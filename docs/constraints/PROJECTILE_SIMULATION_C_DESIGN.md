# DB33弹丸模拟：C类技术设计

## 权限与适用范围

依据实际工作树DB-2026-10-05-33的统一重力、30Hz、弹丸点检测、共享单位碰撞体和发射实际时刻约束。用户明确授权：“这三项设计选择都授权你自行设计，符合C类授权技术细节实现，完成设计后在docs内补充设计文档”。三项对应此前询问的未命中生命周期、积压补算、旋转／尺寸变化求交。

本文件记录该明确授权下的工程决定，不修改DB标识或正式DATA，不将旧寿命、旧单发上限或测试配置追认为正式设计。不新增单位参数类型、schema或类别；所有新状态均为服务器模拟内部状态。AT4准备／携带量、正式编制／N及其他未决项仍未补定。伤害、防护结算、压制、模块、爆炸、击杀与0.6不在范围。

## 时间积压

FixedStepClock累积真实调用者提交的elapsed，以GravityBallistics.STEP_SECONDS逐步执行。每次回调最多8个完整步骤；其余时间全部保留，允许后续elapsed=0继续排空。8为集中C类计算预算，不是每步／每回调弹丸发射数量限制，不调整正式射速，不合并或丢弃事件。

DB29CombatTimeline.advance按每步同一顺序推进MovementSimulation.advance_sampled、FireSimulation.advance_fixed和DB29ProjectileSimulation.step。各通道原有RuntimeWeaponInstance仍是计时／库存唯一权威；步内合法发射继续由既有调度器按实际时刻排序。单步失败不扣除积压；协调器既有halt禁止重复推进已部分执行的失败步骤。无效／非有限时间或累积溢出在变更积压前拒绝。

持续过载会使权威模拟落后于墙钟，这是保留事件而限制单回调工作量的明确代价。预算不保证单步恒定CPU成本；没有声称已通过长期负载分析。活动NetworkManager非legacy入口已按30Hz共享时钟运行，每回调最多8整步并保留债务；显式legacy仅用于历史兼容测试。

## 未命中生命周期

DB29ProjectileSimulation.configure_bounds接收既有地图XZ矩形，不引入新的单位字段。边界必须有限且两轴尺寸为正；有活动弹丸时拒绝更换边界。边界内无固定寿命、距离或高度阈值。

弹丸第一次越过XZ边界时返回battlefield_exit终止事件，按该步XZ线段求精确退出比例，以实际退出时刻计算重力位置、速度与累计距离，并回收槽位及其弹药／来源缓存。位于边界且朝外移动即刻退出；边界外的合法发射仍先返回spawn，再同刻退出。不新增伤害。退出前的真实碰撞优先；同时间精度内保留碰撞优先。

边界未显式配置的隔离调用维持原“无边界终止”行为，不能据此验收完整战场生命周期。地图地面碰撞需由调用者初始化；若测试故意没有地面，XZ静止的垂直弹丸可长期存在，这是场景依赖，不用寿命或高度默认值掩盖。活动链接入时必须配置真实地图边界及静态场景。

## 旋转与尺寸变化

ProjectileUnitMotion每30Hz步骤建立一次共享前后快照和16米空间分区。中心按端点线性插值，旋转取正交旋转基的最短四元数插值，半尺寸线性插值。只接受有限、正半尺寸、正行列式正交旋转基；反射／缩放、非法几何及步内单位拓扑变化拒绝。纯平移继续使用原解析相对线段与箱体求交，不额外分段。

变化箱体以最大端点角点半径覆盖中间所有朝向的空间范围，避免只取前后AABB漏掉旋转中间形状。局部查询只访问空间分区候选，排除发射单位，并截取弹丸实际发射到步末／早先静态碰撞的时间区间。

设查询区间的形状表面位移上界为L（最大角点半径×旋转角度＋半尺寸变化向量长度，再乘区间比例），误差参数ε=0.001米。分段数为max(1,ceil(√3×L/ε))。各段用中点旋转／尺寸及局部平移线段求交，三轴各扩张L/(2×分段数)。真实形状到中点形状的最大位移不超过该扩张量；扩张箱角点额外位移最多√3倍。两者之和不超过ε，采用保守接触，可在该空间误差范围内提前报告擦边接触。ε是工程误差控制，不是弹丸球半径，也不改变单位正式受击尺寸。

误差上界相对于本设计的端点插值模型，不代表重建MovementSimulation在步内全部路径转折或任意多圈旋转。接触时刻与法线属于该保守模型；不声称精确连续刚体求交。大角度／大尺寸变化会增加局部求交段数；不通过任意段数截断放弃误差约束。当前没有每弹丸重建全场或按每个成员分别碰撞。

## 验证与活动链边界

db33_projectile_c_design_test使用生成几何和ConfirmedGameData真实弹药，验证预算／积压／失败、边界退出顺序与时刻、无寿命高度阈值、中间旋转接触／错开时间区间、尺寸增长接触。movement_sampling_test验证真实转向可连续采样、非法几何仍停机及协调器排空完整一秒；原平移、静态遮挡、友军阻挡、稳定同刻仲裁和失败契约回归保留。

原“旋转或尺寸变化一律拒绝”的断言描述旧限制；现改为验证上述获准模型。原停机断言改用非法几何，仍验证失败后不得继续推进，未降低错误检查强度。非冻结实例均为TEST ONLY，正式武器性能不另造；冻结Replay v1旧生命／shot及夹具不修改。

本三项已接入活动权威链。FiringFrame提供实际发射时刻的炮口、目标及准备偏移，共享单位步前后碰撞采样；有frame的入口支持配置允许的运动发射，无frame的旧隔离入口仍拒绝运动。活动TEST ONLY地图与验证范围见HANDOFF；客户端弹丸公开投影已按DB34的PROJECTILE_VISIBILITY_CONTRACT.md接入，真实ENet双端效果尚未验收；完整新战斗回放仍未交付。自动验证与人工验收分别记录在HANDOFF；本文件不授予自动验收结论。
