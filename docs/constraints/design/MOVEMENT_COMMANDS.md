## 11 移动队形与任务队列

| 指令 | 行为 | 路径 |
| --- | --- | --- |
| 基本移动 | 避障外尽量直线，不主动停车接敌 | 蓝色虚线 |
| 快速移动 | 按预计到达时间选路，不增加基础速度 | 绿色虚线 |
| 攻击移动 | 遇有效目标停车交战，结束继续原路线，不追击 | 红色虚线 |
| 倒车 | 装甲适用，保持车头，独立倒车速度 | 黄色虚线 |
| 火炮开火 | 单位到目标指示线，不表示移动路线 | 红色虚线 |

硬化与非硬化路面影响装甲速度，步兵同速。无武器不能攻击移动，步兵不能倒车。路径选中才显示；后续任务虚线和编号，当前与后续均虚线。无效目标禁用符号，火炮准星、移动箭头。

### 局外移动设置

可选按组内最慢有效速度保持队形，或按各自速度。仅本次移动组参与，随地形与移动方式动态计算；乘客按载具，不可移动单位提示并排除。目的地分配不同落点。攻击移动交战单位退出速度协调，其他继续；独立新命令退出组。

避障优先，可暂打破队形，通过后恢复；快速移动仍各自选快路，不强迫同一路线。冲刺暂不受最慢速度限制。

### 禁止掩体吸附

永久不采用掩体吸附（cover snapping）：单位及班组成员不因靠近掩体自动贴墙、对齐或吸附到预设站位，不设置用于该行为的墙边站位槽（slots）及预留机制（reservation）。普通路径避障、队形跟随、房屋进驻与掩体效果仍按各自规则生效，不由本条新增或取消。

### 任务队列

Shift追加，不按Shift替换并清空后续。各单位独立执行，移动到达、装卸完成、指定目标摧毁视为完成。持续攻击地面无结束条件，会阻塞后续。无法执行且目标已失效跳过提示；暂缺弹或空间不足等待。即时烟雾冲刺不入队不覆盖任务。

E在交互状态先退出交互，无交互则取消任务清队列；不启用被关闭武器、不关闭仅还击。H不清队列。混选资格分别检查，不支持单位保留原任务；运输车与车内乘客同选只执行车的移动。

### 地面单位移动碰撞

步兵班组不构成单位级动态寻路障碍；步兵之间、步兵与装甲车辆之间允许移动空间重叠。步兵不阻挡车辆，车辆不阻挡步兵；步兵及班组成员不因其他步兵或车辆进行动态避让，路径规划主体仍为班组／锚点，不为每名士兵增加独立寻路。

装甲车辆采用不随车体朝向改变形状的圆形移动占位。车辆之间的移动阻挡敌我一致，不能相互穿透或最终重叠；自身占位半径、其他车辆当前占位及不可通行静态环境参与路径、目的地合法性与行进碰撞判断。被车辆动态堵住时停止／等待，必要时低频有限重新寻路；停车车辆不被自动推走，受阻不取消原任务。具体半径及重试间隔仍为未定／临时参数，不因本条同步升级为正式数值。

允许移动空间重叠不等于取消受击碰撞体。移动／寻路占位、移动阻挡、受击碰撞体与视觉模型分别处理；车辆圆形移动占位不自动等同真实受击几何。步兵班组保留共用受击碰撞体及人员逻辑位置。

搭载单位不额外占据地面空间，卸载须有有效空位，否则保持搭载。出生点生成同样遵守有效空位规则。

### 残骸与场景障碍物

单位残骸仅作视觉表现，不作为战场可交互实体，不阻挡移动、弹丸或视野，不能选取、攻击、回收或重新操作，不保留补给，不二次殉爆。显示一段时间后消失，时长待定。撤离人员生成不依赖残骸。

场景障碍物被摧毁后换为破损外观，仍按原有范围阻挡移动、弹丸及视野，不新增坍塌碎片、缺口或高度变化。摧毁后不再受伤，不能被彻底清除。单位残骸与场景障碍物分别适用上述规则。
