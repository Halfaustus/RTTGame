# 局内：合作、任务节奏与平衡目标

所属基线：[DESIGN_BASELINE.md](../DESIGN_BASELINE.md)，标识DB-2026-10-06-40。本文是该入口列明的规范正文，不是独立基线。

适用范围：权限、掉线、25分钟PVE任务、战术寿命与弹药窗口；平衡目标不是强制损耗计时器。

<a id="section-16"></a>

## 16 合作权限与掉线撤退

队友单位仅能查看，不能操作；己方单位不能搭乘队友运输车。共享视野、共享补给及共享镭射标记保留。不存在任何控制权转移。

玩家掉线后，可移动单位自动执行返回出生点退款，途中正常受击并计维护费。车内单位随运输车撤退，到达后与载具分别退款，不先卸载。自身基础移速为0的装备，自动触发主动放弃：无需人工确认，仍读条3秒且可被击毁；撤离人员生成后自动返基地。恐慌及失能步兵仍有移动能力，直接撤退，不因此触发放弃。

掉线时取消所有未生成订单（含手持、读秒及等待部署），全额退款释放名额。临时堵路不视为无法移动，继续等待通路。在线玩家继续对局，不暂停、不因队友掉线直接判负。当前不提供断线重连，不设计恢复任务等流程。

正常对局经济账户独立，初始余额与基础收入按[第3节](DEPLOYMENT_ECONOMY.md#section-3)，不能直接转账。掉线后该玩家后续基础收入均分给在线队友，开局总基础收入保持不变。设开局玩家数N、在线人数n>0，每名在线玩家基础收入为300N/n分/分钟，每5秒到账25N/n；双人剩一人为600/分钟、50/5秒。维护费仍各自计算，不把掉线单位维护转嫁给队友。掉线玩家原余额、订单退款及撤退退款不分给在线玩家；掉线玩家不再领取基础收入。无人在线时不分配收入。

地面补给点不属于单个玩家，掉线不移除，按队伍归属继续服务。移动补给车随单位撤退，途中仅在正常停车服务条件成立时提供补给，不为补满队友而停留；携带库存随车撤离，不主动卸下。

## 25 战斗节奏与单位生存性

本节为用户确认的现行基线，覆盖旧的较长TTK／生存时间设定。平衡目标不是硬性倒计时，不直接授权修改正式DATA或扩展当前实现阶段。

### 模式与首版边界

核心模式为单人／双人合作PVE。标准任务局内时间固定为25分钟，阶段及节奏按[第25节](MATCH_MISSION.md#section-25)；首个任务为据点防守，敌军完全占领即失败，坚持到结束未完全失守即胜利，不要求清敌。首版一个阵营、两个专精、一张地图，具体波次暂跳过。叛军复用既有单位；虫族与机器人尚无已确认实现规则。全体系规划步兵、装甲、快速及未来空军专精，航空尚未启用，但基础弹丸设计须兼容空对空导弹与投弹。

### 标准任务时间结构

标准任务固定25分钟：

| 阶段 | 时间 | 目标 |
| --- | --- | --- |
| 战前部署 | 0–1分钟 | 购买、编组、部署、交流思路、分配任务和规划机动轴线；所有单位冻结，不得提前出动 |
| 展开 | 1–9分钟 | 部队展开与武装侦察；先头约2–3分钟进入可能接触地域，开局主要支援约3–5分钟形成有效作战能力；允许短促、小规模、高杀伤交火，原则上不普遍提前发展为全部主力决战；第9分钟基本建立态势和展开主要战斗体系 |
| 全面战斗 | 9–17分钟 | 主要8分钟高强度窗口；突破、反击、火力集中和阵地争夺集中于此；正常配置且无明显弹药浪费的主战单位无需补给完成该窗口 |
| 后续作战 | 17–25分钟 | 先期力量明显人员、装备和弹药损耗；选择继续使用、撤出补给维修、投入预备队、集中余力扩大战果或最后高风险反击；不得成为垃圾时间，优势须通过纵深推进、保持关键地域或完成后续任务转为最终胜利 |

### 生存性与核心杀伤原则

单位生存时间从首次有效接敌起，计算到无法有效继续承担原有战术任务，而非生成到彻底摧毁。战术失能可来自严重减员、关键武器损失、主武器或机动系统损坏、弹药耗尽、严重压制、被迫撤离或完全摧毁；失能率不等同死亡率或装备彻底毁伤率。本节定义不替换[第9节](COMBAT_RULES.md#section-9)压制失能状态与阈值。

采用“接敌慢，决胜快”。通过侦察、隐蔽、掩体、机动、射界控制和阶段性交火延长寿命；被发现且暴露于有效杀伤手段后，不依赖高生命值长期承受攻击。禁止HP海绵，寿命主要来自避免有效攻击。

### 局部失能时间

前提为目标已发现、射击条件基本成立、持续受到匹配武器有效攻击：

| 作战情况 | 平衡目标 |
| --- | --- |
| 开阔地步兵遭有效火力覆盖 | 10–30秒显著减员或失能 |
| 普通掩体步兵正面交火 | 45–120秒分出明显结果 |
| 强固地形步兵防御 | 2–4分钟 |
| AT、机枪、观察组暴露且准确发现 | 10–20秒进入极高损失风险 |
| 轻型车辆遭匹配反装甲火力捕获 | 3–10秒 |
| APC／IFV遭匹配反装甲武器有效攻击 | 5–20秒 |
| 坦克进入敌方已建立射击条件的有效杀伤区 | 5–15秒出现首辆失能 |
| 坦克双方利用掩体和机动局部交战 | 30–120秒形成明显结果 |
| 迫击炮／炮兵可靠定位后受到有效反制 | 30–60秒内开始转移，否则损失风险快速升高 |

允许武器、地形、训练水平、数量优势和战术态势造成较大波动；训练水平描述不新增未经确认的训练属性或经验成长机制。

### 战术寿命与全局损耗

正常使用，从首次有效接敌计算：

| 类别 | 典型战术寿命 |
| --- | --- |
| 先头侦察、轻型前出力量 | 3–6分钟 |
| 普通步兵、IFV等前线单位 | 5–8分钟 |
| 主战坦克 | 6–10分钟 |
| 火力支援 | 10–20分钟，良好使用允许存活整局 |
| 指挥、补给、维修 | 正常情况下有存活整局的可能 |

不自动失效；未持续暴露于有效火力的单位可远超典型寿命并存活至任务结束。

双方实力接近、任务正常发展且强度符合预期时，以开局投入的前线战斗力量为基准：

| 时间 | 累计完全或基本失能比例参考 |
| --- | --- |
| 第9分钟 | 10–20% |
| 第17分钟 | 35–50% |
| 第25分钟 | 55–75% |

仅作整体平衡审计，不强制执行损耗曲线。第17分钟理想状态为前沿明显损耗、整体体系仍在，为最后8分钟预备队、重整、补给与反击提供基础。

### 预备队、弹药与支援

预备队用于替换严重减员先头力量、接替缺弹或受损主力、利用敌方前16分钟暴露的薄弱方向、形成新突破及劣势下最后反击，不只是替换完全死亡单位。同一时刻前线实际交战力量可维持营级，整局累计投入可达加强营乃至旅级；不据此新增编制或在场数量硬限制。

完整、弹药配置正常的主战单位进入9–17分钟阶段，应无需常规补给完成8分钟正常高强度作战。持续最大射速压制、无效射击或异常高强度允许提前耗尽；补给压力主要在17–25分钟明显出现，不在全面战斗开始后立即成为常态。

开局迫击炮、近程防空、指挥保障及主要营属支援应在任务开始约3–5分钟内完成必要机动展开并形成有效作战能力，不因后方属性长期脱离战斗。生存依赖阵地选择、隐蔽和转移，不依赖高耐久。

### 不采用经验／老兵成长

不设以存活、击杀或作战时间为基础的经验等级、老兵等级或永久战斗属性加成。同型号、同状态的长期存活单位与新投入单位无经验属性差异。存活本身就是正确侦察、部署、机动和风险控制的收益，不再附加数值成长奖励。

### 数值校验与步兵班标定

单位可在战场存在很久，但不能在有效火力下存在很久。战术寿命主要5–10分钟，局部有效杀伤主要数秒至两分钟；部署后的前8分钟建立态势、中间8分钟主要损耗、最后8分钟处理损耗并投入预备力量。伤害、命中率、压制、掩体、防护、维修和价格须接受这些尺度的反向校验。

下一设计工作优先细化步兵班减员模型。人员生命、直射／爆炸分配、碰撞与岗位接替沿用[第9节](COMBAT_RULES.md#section-9)、[第18节](PROJECTILES.md#section-18)。不通过提高HP、隐藏命中率或强制减员倒计时满足目标。成员选择细则、标定实例及未确认阈值仍待细化，时间目标不自动批准具体参数或伤害系统实现。
