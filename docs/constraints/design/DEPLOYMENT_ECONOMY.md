## 3 出动分维护与退款

| 参数 | 数值或规则 |
| --- | --- |
| 初始出动分 | 1000 |
| 基础收入 | 每分钟300，每5秒到账25 |
| 地面维护 | 在场单位配置出动分的5%每分钟 |
| 空军维护 | 在场单位配置出动分的2.5%每分钟 |
| 结算周期 | 5秒；每次维护为每分钟费用除以12 |
| 补给购买 | 10出动分每1t；不计维护费 |
| 精度 | 内部浮点计算，界面整数去尾 |

单位配置的价值分与出动分独立配置，均须为非负整数且为5的倍数；非法值拒绝，不取整。维护费与退款允许小数计算。价值分与出动分独立定价，6000价值分作战群的全部部署费用不必是6000。收入与维护同时结算；净支出扣存款，余额最低0，无负债。无法支付维护不使现有单位损血、消失或失去作战能力；购买必须余额足够。撤离人员不免维护费。

此处单位配置出动分包含完成配置的单位及其装备价格，不含另购补给费用；“本体费用”不表示单位基体具有独立购买价格。退款公式中的单位出动分采用同一口径。

### 退款

B返回基地退款区域，到达后移除单位，释放名额。退款＝max[0，（单位出动分－当前缺失弹药对应费用）×0.1]。残编、生命值与模块损伤不影响退款；具体弹药费用与补给类型后续设置。正常退款不计击杀或死亡价值，单独记录金额。

返回途中仍可被击杀且收维护费；其他任务指令取消返基地任务。运输车与自己的车内单位可共同移除，各自计算退款后相加；剩余车载补给不额外退款。移速为0火炮须乘车返回，可随运输单位退款。

主动放弃不继承原装备弹药缺额到撤离人员，撤离人员仅按自身数值及弹药状态退款。出动订单生成前取消整单全额退款，包括补给。

### 价值统计

价值分既用于组卡，也等于正常击杀与死亡统计分值。价值KD＝累计击杀价值÷累计死亡价值；死亡价值0显示“无损”，不显示单位数量KD。班组全灭一次性结算整班价值，单兵伤亡不单独得分；补员不改变价值。最后造成消灭的单位获得击杀，其他参与者记录助攻，不额外产生价值分。

## 4 购买与出动订单

购买入口为单位类型列表→具体单位列表；具体单位条目引用已编入作战群的完整单位配置，不直接出售单位基体。单位选定后选择出行方式；运输载具选定后选择乘客和补给吨位，可空载。出行方式决定自行移动或搭乘载具；载具与乘客必须来自已编入作战群的配置。移速为0的架设火炮必须绑定卡车出动。

确认购买即扣除各组成单位及补给费用，分别预留对应名额。已有在场数量＋待生成订单数量不能超过每卡选定上限。尚未生成的订单同样占名额，不收维护费。购买后生成一个暗化处理的兵牌作为订单位置指示；该暗化兵牌仅表示未来单位的目标位置，不是实际单位，不侦察、占点、受攻击或获得实际单位状态。其尺寸、单位识别图案和玩家颜色边框与对应实际兵牌完全一致，仅做暗化处理。组合订单仍使用一个订单位置指示，具体组合识别图案若需区别后续再定。

| 步骤 | 操作 |
| --- | --- |
| 购买后 | 生成暗化兵牌并跟随鼠标 |
| 放置 | 左键地图指定目的地，开始生成读秒 |
| 调整 | 第一次左键点击暗化兵牌拿起，中止读秒；第二次左键放下，重新完整读秒 |
| 取消 | 手持时右键或E取消；读秒中右键点击暗化兵牌取消；全额退款并释放名额 |
| 生成 | 地面3秒，空军6秒；出生点生成，前往暗化兵牌所指示的位置 |

同时只能拿起一个订单位置指示，多张已放置订单并行读秒。无效位置使用禁用符号提示，不使用红色区分无效与攻击。订单身份与兵牌样式统一按本节购买规则。

### 出生与默认行为

当前使用固定地面通用出生点，后续任务可加限定种类入口和独立空军入口。局外设置出场基本移动或快速移动，以及到达后卸载或保持搭载。生成时乘客已搭载，维护从生成后开始。

到达卸载只在目的地执行，途中遇敌不自动卸载；空间不足保持搭载并提示。修改出动移动命令取消原地自动卸载安排；卸载后载具留在原地。到场前取消指生成前取消，不包括生成后的赶路阶段。

<a id="section-17"></a>

## 17 部署受阻

读秒结束在出生点范围寻找最近有效空位。无空位时等待部署，保留费用与预留名额，不收维护；有空位后直接生成，无需重新读秒。等待期间可拿起订单暗化兵牌调整位置，放下重新完整读秒，取消全额退款。按读秒完成先后部署，但某个订单尺寸受阻不阻塞其他可部署订单。敌人接近不关闭出生点，新单位没有无敌保护。

已生成单位无法到达订单暗化兵牌所指示的目的地时，前往最近可达位置并提示，不自动退款；卸载空间不足保持搭载。
