# 局内：运输、撤离与补给

所属基线：[DESIGN_BASELINE.md](../DESIGN_BASELINE.md)，标识DB-2026-10-08-42。本文是该入口列明的规范正文，不是独立基线。

适用范围：运输容量、装卸、损失、撤离人员、补给服务、修复及殉爆。

<a id="section-5"></a>

## 5 运输容量与装卸

关联关系按[第2节](OUT_OF_MATCH.md#section-2)，不作为运输许可名单。运输资格仅检查最大乘员与重量，不另加可运输类型标签。步兵固定运输重量＝满编人数×0.1t＋特殊装备重量，撤离人员同样适用；占位与消耗变化按下文总运输载重规则。

### 总运输载重

运输单位设置“最大乘员数”和“总运输载重”。搭载人员、特殊装备及车载补给共用一个总载重池，任意组合的总重量均不得超过总运输载重；最大乘员数为独立硬限制，不因剩余载重充足而放宽。

设所载人员及特殊装备固定重量为C、现有补给重量为B、总运输载重为L，则须C+B≤L，并同时满足最大乘员数限制。人员按满编占位与固定重量计入，伤亡及弹药消耗不释放乘客占用；补给实际消耗降低补给重量并释放对应载重。具体单位若设置补给携带上限，该上限只限制补给数量，不形成独立或不可挪用的容量分区。

### 装卸行为

装载采用选单位后右键运输车；双方靠近停车。不能自行移动的火炮由车辆靠近装载；失能步兵仍可低速登车。装卸时间按待载单位配置独立设置，步兵较快、火炮车辆较慢，不增加火炮架设时间。

装卸期间双方不能移动或射击，仅受攻击不中断。恐慌和失能均不禁止步兵装载或卸载，不增加装卸时间；读条期间进入失能也不暂停或清零进度。卸载保留生命、人数及压制状态，搭乘不解除失能。装载完成前单位在车外，卸载完成前仍在车内，完成才切换状态。移动或取消会清零进度并保留原位置；开始装载预留容量，装载前须将现有补给计入总载重，容量不足则拒绝登车，不以自动丢弃补给腾出空间。多单位按单位条目顺序执行，不拆班，乘员位不足或重量超限时跳过并在右侧战场信息栏统一提示“载重不足”。装卸不消耗补给。

### 运输损失

车内单位不能射击或成为单独攻击目标。运输车被毁时，普通步兵强制卸载，每名士兵受固定伤害、班组增加固定压制且至少恐慌；达到失能阈值则失能。不再叠加摧毁车辆的同一次攻击伤害。伤害与压制值待定。车载补给全部损失，不殉爆。所有架设火炮班组沿用步兵乘客固定伤害与压制逃生规则，不再直接摧毁或50%生成撤离人员；所载车辆直接摧毁，撤离人员生成见下一节。

<a id="section-6"></a>

## 6 主动放弃与撤离人员

统一名称“撤离人员”，视作一种普通步兵，只能由撤离事件生成，不能直接购买。不重新操作装备，可治疗补员、运输、自卫与退款，武器为阵营对应PDW，属于正常枪械，数值偏低。

| 事件 | 人员生成 | 原装备计分 |
| --- | --- | --- |
| 地面装备正常被击毁 | 不生成 | 全额价值 |
| 所载车辆随运输车摧毁 | 每个被运输单位独立50%概率生成 | 全额价值 |
| 飞机被击毁 | 50%概率跳伞生成 | 全额价值 |
| 主动放弃或主动跳伞 | 完成放弃后生成 | 少量价值，比例待定 |
| 飞机燃油耗尽 | 自动按主动放弃处理并生成 | 少量价值 |

运输车本身不因正常被毁生成撤离人员。普通步兵乘客强制卸载使用运输伤亡规则，不使用50%抽样。

### 主动操作

主动放弃需要二次确认，再读条3秒；地面单位期间不能移动，仍可被正常击毁。读条内被毁按正常摧毁，不重复生成。燃油耗尽自动触发，无需确认，具体航空动作待航空系统细化。

主动放弃击杀者显示“本单位／自身”，对方队伍获得少量价值；被动逃生不减少原装备击杀分。撤离人员再次被击杀仅按自身低价值分结算。

### 名额与退款

原装备消失立即释放原卡名额，撤离人员不继承名额、不占卡种名额。人员生成即恐慌，出动分与原单位相当且正常计维护。返回基地用普通退款流程，金额按自身出动分和自身弹药缺额计算；人数损失不降低固定配置出动分。全员阵亡无退款。

<a id="section-7"></a>

## 7 补给来源与服务

补给只在出生点随部署购买，玩家自选吨位，价格按[第3节](DEPLOYMENT_ECONOMY.md#section-3)；不能在场上生产，也没有基地免费补充。通过现有库存转运持续供给。

| 补给单位配置 | 车载服务 | 库存装卸 |
| --- | --- | --- |
| 移动补给 | 作为移动补给点，为步兵补弹；不能治疗补员 | 可从地面点装载，不能卸下建点 |
| 无移动补给标签（默认建点方式） | 车载库存不能直接服务 | 卸下才成为完整补给点；可从已有点装回运往他处 |

仅保留单位能力标签“移动补给”，取消“建造补给点”标签。具有补给能力而无移动补给标签的单位默认采用建点方式；普通单位不会因缺少标签获得补给能力。移动补给车不参与地面堆合并。步兵专精补给步战车按此限制提供服务。

### 地面点与合并

地面补给点保留队伍所属信息，不记录来源玩家；所属队伍各玩家均能正常使用，并由符合补给能力及移动补给标签规则的载具装载库存、转运和卸下建点，受容量限制。补给车仍有玩家归属和操作权限，只共用补给服务规则，不参与占领。

补给点采用敌方／中立／己方三态，沿用据点占领规则：先清敌再填己，固定速度，单位状态与数量不影响速度，双方在范围内暂停，无人保进度。量表缩短至近乎瞬间占领，具体时长待定。敌方须先占领才能使用或装载，占领不改变剩余库存。补给点不计任务据点数量，不推进PVP占领分；补给点自身不能作为占领单位。

只有同队补给点可自动合并。新点进入己方已有点范围，或中立／敌方点被占领后满足合并条件时，必须并入先创建的己方补给点；多个符合条件则选最早创建的己方点。被占领点自身的旧创建时间不能让已有己方点迁移。移除原点，在接收点位置形成总库存补给点，沿用接收点范围及创建顺序，不扩大范围。无符合条件点则独立保留。合并无退款、击杀、死亡或殉爆。运输单位不合并。库存耗尽点消失，无主动销毁补给操作。

### 服务条件

受补单位停车且停止开火才接受服务，移动或开火暂停，仅受攻击不强制中断一般服务。移动补给双方需停车。车内乘员按车辆位置接受地面点服务，移动补给可服务自身步兵乘客。恢复完成的效果保留，不重复扣费。

弹药补充和人员恢复并行，各项独立进行，不共享总补给速率但共享库存。每班组同一时刻只结算一次，不因来源重叠加速；来源耗尽自动切换。补给速度与范围按配置设置。车辆模块维修保留其受击中断与安全时间要求，见模块规则。

## 8 补给消耗与殉爆

| 项目 | 当前消耗 |
| --- | --- |
| 步兵治疗 | 0.025t每恢复1生命 |
| 补员 | 0.2t每人，补入生命5 |
| 模块维修 | 0.25t每修复一个损伤等级 |
| 车辆生命值恢复 | 待定 |
| 弹药与烟雾 | 具体类型和吨位待定 |

模块维修按损伤等级计费。人员补给顺序为补员→治疗；失能自动解除，不单独消耗补给。弹药独立并行。完成一次扣一次，库存不足暂停该项，其他较小费用可继续；同刻争库存按开始接受补给顺序处理，不出现负库存。

### 地面补给点属性

补给点可被攻击，不提供侦察，自身不占其他据点；生命值1，动能防护5，化学能防护5，按现有防护伤害公式结算；服务及占领范围待数值配置。摧毁敌方补给点按剩余吨位×10计入攻击方击杀价值和队伍补给损失，不计来源玩家个人死亡价值；摧毁己方或中立点无击杀价值，仍可能殉爆。车载库存损失与本体价值分开记录，补给不参与维护。

### 殉爆

只有地面补给点被毁且剩余库存≥1t才殉爆，少于1t不触发；车载库存不殉爆。伤害＝伤害系数×剩余吨位。半径＝范围系数×剩余吨位，再限制在最小与最大半径内，系数及上下限待定。

殉爆带特效，按既有爆炸距离衰减与防护处理，步兵按人员位置受伤与压制。伤害双方单位，可引爆附近其他补给点；每点只触发一次。连锁击杀归最初引爆的攻击单位；友军损失计死亡价值，不增加攻击方击杀价值。
