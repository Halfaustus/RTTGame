## 23 场景实体、驻扎与比例减伤

### 场景实体分类

场景实体由服务器统一管理，可由地图预先放置，不必属于中立作战单位；不参与单位卡、维护费或单位价值KD。房屋不取得玩家归属，只记录内部人员及其队伍。

| 类型 | 规则 |
| --- | --- |
| 树林 | 范围内隐蔽×2；无物理碰撞，不阻挡移动、弹丸，也不额外遮断视线 |
| 障碍物 | 物理遮挡弹道与视线；移动阻挡沿用场景设置 |
| 房屋 | 遮挡弹道与视线，可进驻步兵；毁后保留阻挡但不能再次进驻 |

树林范围统一以单位中心判定；步兵按班组中心，整班同时获得／失去加成，车辆按自身中心。不逐士兵判定，重叠树林只翻倍，不叠加。树林是否可受伤／摧毁未确定，不自动套用房屋规则。

### 房屋进驻

房屋仅设置最大容纳人数，不计算载重；班组按满编人数占容量，伤亡不减占用，只能整班进入。同队不同玩家可以共同驻扎，各自指挥自己的步兵。已有敌方驻军时不能进入，不增加室内近战争夺。

选步兵右键房屋进驻，U离开；直接移动命令先离开再前往目的地。进出统一短读条，时长待定，不受恐慌／失能延长。人员生命、人数、压制及武器手动开关不因进出改变。

每把武器单独设置“房屋内可开火”标签；不允许的停火，允许的正常使用，不因某把武器禁用而禁止整班进驻。离开后恢复室外资格，不打开玩家关闭的武器。弹丸从房屋几何中心发出，忽略所在房屋自身碰撞；其他地形、建筑和单位照常阻挡，不计算窗户或射界。

### 攻击驻军与房屋毁损

被发现驻军仍可作为独立单位目标，位置视为房屋中心。指定攻击驻军的弹道忽略所在房屋阻挡，按步兵防护及减伤结算。指定攻击房屋只直接扣房屋生命，同一次直击不同时扣二者；爆炸可以分别伤及房屋与内部班组，每个对象结算一次。

房屋被毁强制内部步兵离开，承受固定逃生伤害与压制，不重复承受摧毁房屋的同一次攻击伤害；固定逃生数值待定，沿用运输损失思路。毁后房屋换破损外观，保留原阻挡范围，不再受伤、不能清除或再次进驻。

### 减伤比例与减伤无视

比例减伤在动能／化学防护结算之后应用，浮点伤害：

有效减伤＝最高适用减伤比例×（1－弹药减伤无视比例）。

最终伤害＝防护结算后伤害×（1－有效减伤）。

比例减伤仅由掩体保护提供。步兵本体无自身比例减伤，平静、恐慌、失能状态均不赋予比例减伤；无掩体步兵按防护公式直接结算生命伤害。不同类型掩体分别配置减伤比例，具体数值后续确定，不沿用房屋统一50%的旧默认值。步兵动能／化学能防护仍保留，不与比例减伤混同。

多个适用掩体减伤来源只取最高，不叠加。人员状态变化不取消已有掩体保护。掩体自身不自动享受其向驻军提供的减伤；固定逃生伤害不享受该房屋驻扎减伤。

减伤及无视只改变生命伤害，不改变击穿判定、动能／化学防护、压制或模块破坏，不绕过遮挡。每把武器设置减伤无视比例，范围0%～100%，具体数值以后定义，不预设直射0%或曲射100%。普通无其他来源的比例减伤默认为0%，减伤比例范围0%～100%。

### 通用隐蔽、暴露与消音

单位具有基础隐蔽倍率，普通基准1；发现距离＝观察者视野距离÷目标有效隐蔽倍率，同时检查地形视线，并沿用队伍共享发现。基础数值按单位以后设置。

实际发射武器后，有效隐蔽倍率暂降至1；停火一段时间恢复基础与树林加成。移动、瞄准、装填不触发额外暴露，离开树林立即取消树林加成。开火不全图点亮，仍需满足发现距离与视线。

每把武器可有“消音”标签，缩减比例为统一固定值，不随武器、阵营、人员状态等变化，具体值待定：该武器暴露持续时间＝基础暴露时间×（1－消音缩减比例）。每次发射刷新该武器造成的暴露，直到班组所有武器造成的暴露均结束才恢复隐蔽。消音不改变瞬间隐蔽损失，不减伤，不新增声音传播或听觉侦测；持续时间与缩减比例待定。

烟雾保持遮断视线，无物理碰撞，不挡移动弹丸，不提供隐蔽倍率。开火不能看穿烟雾；烟雾内仍计算通用暴露，但发现必须满足视线条件。烟雾继续阻断镭射。
