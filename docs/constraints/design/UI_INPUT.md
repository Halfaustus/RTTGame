## 14 兵牌、详细信息面板与鼠标交互

### 兵牌主体

兵牌是最小可独立指挥单位在场上的唯一权威位置指示：步兵以班组为最小单位，装甲以单车为最小单位。兵牌与单位当前模型的位置绑定，当前模型可使用自动生成占位模型，后续替换正式模型不改变兵牌规则。兵牌采用固定屏幕尺寸，不随世界缩放变化；Demo阶段密集单位兵牌不做自动偏移或避让，允许发生重叠，后续保留优化可能。

兵牌主体统一为玩家颜色矩形边框＋灰色填充背景＋中央单位识别图案。当前玩家所属单位在自己的客户端显示蓝色，在其他玩家客户端显示绿色；颜色是本地观察者相对归属表现，不改变服务器所有权。未来待办：扩展可支持玩家数量，并允许玩家自定义其他玩家在自己客户端的颜色；本轮不启用这些扩展。玩家颜色边框只承担归属识别。具体识别图案、美术图标、槽位尺寸及间距后续替换或细化，不改变本节信息结构。兵牌本体不附生命条，不常驻显示单位名称、武器、弹药、速度等详细数值。

人员正常时使用灰色填充；恐慌时兵牌主体改为黄色－灰色渐变填充；失能时改为红色－灰色渐变填充。该人员状态表达同时适用于步兵与装甲。步兵另在兵牌下方显示阿拉伯数字的当前班组人数，班组人数属于独立指示器，不归入生存状态指示器。

### 兵牌派生状态指示器

状态指示器均从兵牌位置派生，不独立代表单位。现行类别保留为生存状态、工作状态、开火、行为状态和搭载状态。具体图标以后加入，当前只固定框架、位置和语义。

| 类别 | 位置与规则 |
| --- | --- |
| 生存状态 | 人员状态通过兵牌主体背景表达。装甲另在右侧自上而下预留观瞄、装填、机动三个状态槽；正常隐藏，轻度受损黄、重度受损红 |
| 工作状态 | 兵牌左侧自上而下固定为镭射、禁火、交战中三个独立槽位；三者互不排斥，可同时存在；未激活时不显示具体图标 |
| 开火指示器 | 仅装甲单位使用，位于兵牌下方；统一白色进度条，只提示距离下一次开火的剩余时间。瞄准与装填同时存在时，显示预计更晚完成、即实际限制下一次开火时间的那一项；两者均完成时隐藏。当前机炮按机炮炮塔处理，车载武器仍指炮塔／车体派生的车载武器槽位中的武器 |
| 行为状态 | 保留独立类别，沿用现有可见性和行为规则；当前已定义的仅还击状态仍只对己方显示，不在详细信息面板重复 |
| 搭载状态 | 位于兵牌上方；仅搭载步兵时显示搭载人数，存在混合货物时仅显示搭载图标，不用数字表示混合载荷 |

受损状态对双方的可见性继续沿用既有规则：敌方仅在点亮时获得实时状态，失视后不泄露新的变化。所有兵牌派生状态均不增加悬停文字。

### 主HUD与详细信息面板

当前主HUD信息架构固定为：左侧预留单位订购／出动区域，右侧为战场信息栏，左下保留小地图，小地图右侧延伸为底部详细信息面板；中央主体尽量留给战场视野，仅叠加兵牌、选择反馈、订单指示及必要战术反馈。现阶段只固定信息架构与交互，不绑定最终美术；图标、字体、材质、单位缩略图等美术资源后续补充，允许使用字符、几何图形和临时矢量占位。概念预览图不属于基线资产，也不嵌入本基线。

底部区域按从左到右固定为“小地图｜武器信息｜单位摘要｜命令区”。单选后显示对应详细信息；详细信息面板不是兵牌，不承担场上位置指示。单位摘要只显示单位身份与总体存量信息：名称、单位类别／配置、总生命；步兵另显示存活／满编人数。兵牌已承担人员状态、装甲观瞄／装填／机动受损、工作状态、开火与搭载等状态提示，因此详细信息面板不重复这些状态；不显示视野、隐蔽等细数值。

武器信息区横向单排并列显示武器类型，超宽时横向滚动，不自动换成第二排。同型号武器合并为“武器名×N”，不展示炮塔、Mount、Weapon Slot或车体／炮塔派生关系；车载武器与班组基本武器采用相同汇总方式。每种武器下方按弹药种类分列该武器类型的当前合计库存，只显示合计弹药，不提供单把武器库存展开。弹药耗尽时保留该弹种并置灰，不因归零而隐藏。步兵班组同型号武器已经按运行通道合并时，界面显示该通道的瞄准与装填状态，不再要求显示同型号内部逐把武器的就绪数；未被通道合并的独立武器仍按各自状态表达。烟雾属于单位能力，不作为武器或弹药卡单独列入武器区。

命令区采用固定3×3槽位，单位不具备某项操作时该槽位留空，不允许其他按钮补位。按从上到下、从左到右固定为：

| 行 | 左 | 中 | 右 |
| --- | --- | --- | --- |
| 1 | 冲刺／快速移动 | 攻击移动 | 倒车 |
| 2 | 烟雾 | 强制开火／T火炮 | 仅还击 |
| 3 | 镭射 | 装卸 | 返回基地 |

第一格按单位资格显示冲刺或快速移动：当前步兵无快速移动、装甲无冲刺，两者共用槽位且不需要二级菜单。第二行中格对普通直射单位显示强制开火，对火炮显示T火炮入口；当前地面UI中T仅作为火炮入口，其二级菜单覆盖原命令区位置。返回基地固定在右下角并使用黄褐色作为视觉强调。普通移动与普通攻击不设命令区按钮，继续使用既有地图直接交互；需目标的命令仍由地图右键确认，即时能力点击执行。仅还击按钮亮开暗关、混合半亮；仅还击状态仍只在己方兵牌旁显示，详细信息面板不重复。

### 多选与快捷选择

多选单位条目排序侦查→步兵→装甲→支援→飞机，同类按配置且不因状态跳位，超宽横滚。多选武器区显示多单位，菜单取可用操作并集。

单击场上兵牌或Tab循环单单位，保留原集合，指令只对当前单位；Shift+Tab恢复集合。Tab按面板单位条目顺序，阵亡退出删去，当前死亡切下一。双击场上兵牌选屏幕内当前可控同型号同配置单位，不含订单。

### 消息与交互

所有文字提示除当前操作类型外进入右侧战场信息栏，无悬停文字；重复原因去重，同批合并，可定位单位、淡出并展开历史。失败尝试或重要状态变化提示，不在鼠标经过时弹。正常成功靠动画路径反馈。左侧屏幕空间保留给单位订购／出动UI，不再承担消息栏。

普通左键选、拖框选、空地清空，Shift左键增减，Shift框选加入。指令选点右键确认、左键或E退出且不穿透选择；Esc只开菜单。手持订单暗化兵牌左放右取消，E取消订单。界面点击不穿透。

## 15 键位与共键互斥

| 键位 | 功能 |
| --- | --- |
| W A S D | 镜头移动 |
| Q | 地面攻击移动或敌方指定攻击 |
| E | 退出交互；无交互时取消任务清队列 |
| Esc | 打开菜单 |
| R / F / G | 倒车 / 快速移动 / 强制开火 |
| H | 仅还击开关 |
| T | 火炮开火／未来导弹精确打击／飞机精确投弹 |
| U / B | 卸载 / 返回基地退款 |
| X | 烟雾／未来干扰物 |
| Z | 冲刺／雷达操作／未来增压 |
| C / Y / V | 改变高度 / 镭射指示 / 空投（高度与空投待航空启用） |
| Shift | 追加任务 |
| Tab / Shift 加 Tab | 循环单选 / 恢复原多选 |
| Ctrl 加数字 | 保存覆盖编组，1至9及0 |
| 数字 / 连按数字 | 选择编组 / 定位镜头至组中心 |
| Shift 加数字 | 编组加入当前选择 |

同一单位的X、Z、T各只能具备一种对应操作，局外配置提示互斥。多选含同键不同操作时提示“存在互斥操作”，该键整组忽略，菜单隐藏对应项。没有对应操作不算冲突；冷却缺弹仍算拥有操作。只有一种操作正常显示菜单及CD，不需要例外。Q的目标语境不属于互斥。

统一用“增压”“干扰物”，原涡轮及热诱称呼取消。J与X合并至X，J不绑定；K L N O P旧绑定取消，不单设导弹炸弹键。

同一单位可属于多编组，编组不改任务。退出战场移除，补购不自动加入；Tab单选保存只含当前单位。载员保编组但移动不自动卸载。空组不改选择。
