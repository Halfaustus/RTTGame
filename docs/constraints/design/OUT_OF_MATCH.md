# 局外：阵营、专精与作战群

所属基线：[DESIGN_BASELINE.md](../DESIGN_BASELINE.md)，标识DB-2026-10-06-40。本文是该入口列明的规范正文，不是独立基线。

适用范围：战前单位池、类别预算、单位卡和关联组卡。

<a id="section-1"></a>

## 1 阵营专精与单位分类

### 阵营与专精配置

阵营与专精的风格、作战定位及典型装备见 `docs/RTTGame_DESIGN_PRINCIPLES.md`（当前未找到，不据此补造设计）。专精决定可用单位池；玩家选择同阵营的两个专精，合并单位池及类别预算。

专精类别为步兵、装甲、快速及空军；空军随航空系统启用。每个专精须具备基础反人、反甲、防空、侦察和补给手段。班组人数主要由阵营和单位配置确定；专精差异通过卡种、价格及允许在场数量表达，不直接规定班组人数。

### 按实际作战环境分为五类

| 类别 | 范围 |
| --- | --- |
| 侦查 | 以高视野获取情报的班组和车辆 |
| 步兵 | 作战步兵及主要伴随步兵的步战车、运载车 |
| 装甲 | 坦克和以独立地面直接交战为主的车辆 |
| 支援 | 炮兵、防空导弹、高炮、步兵迫击炮及后方运输补给 |
| 飞机 | 航空单位，暂不启用，额度为0 |

分类决定预算，单位类型决定伤亡和运输规则。步兵迫击炮属于支援预算、步兵类型；所有架设火炮属于支援预算、步兵类型，统一为步兵班组＋特殊武器。是否拥有车辆底盘不决定编组类别。支援类别不限制单位进入前线或执行合法移动。

## 2 作战群预算与单位卡

### 价值分预算

每个专精的五类额度合计3000，当前飞机额度为0，其余四类合计3000。两个同阵营专精的同类额度相加，总计6000。每类支出最多达到该类合并额度的110%，所有常规卡总支出不得超过6000；零额度仍为零，不强迫凑满预算。

卡片支出＝所选配置价值分单价×玩家选定最大在场数量。单位配置固定归类，不由玩家自行更改。同一型号不同配置各算一个卡种；常规卡种共用上限，具体数目待定。每卡独立限制在场数量，不另设全军在场总量上限，也不限制整局累计购买数量。

### 关联组卡

先选择步兵，再可关联步战车或运载车；卡车也可关联架设火炮，补给是运输单位的通用关联选择。主单位和关联单位合计价值后计入所属类别，关联仅用于组卡界面，不永久绑定局内对象。局内各组成单位可分别购买、指挥和补购，各自检查名额。

相同型号相同配置在两个专精中重复出现时，单位池去重，不重复叠加携带上限。具体关联组合的配置呈现与分项数量配置还需在组卡界面落地。
