# RTTGame 设计基线

基线标识：DB-2026-10-04-01。状态：已确认规则汇编。日期：2026-10-04（北京时间）。目标路径：`docs/DESIGN_BASELINE.md`。

## 0 文档职责与范围

本文件是游戏设计的唯一现行基线，规定游戏应怎样运行，不代表任何功能已经实现。来源为《RTT项目计划书_v3》及本会话截至本次请求的已确认修订。v3保留为历史项目书，不作为冲突时的第二套现行规则。其他会话未完整提供的设计不推断补齐；跨会话文档发生冲突须明确报告，确认后更新正文。

每批设计讨论结束整理新增／替换／删除／待定四类变更；已确认变化更新正文，旧规则只保留在变更记录。待定项不作为已批准开发要求。提示词仅指定本轮范围及新增变化，不复制整套规则形成另一份基线。

`HANDOFF.md`仅记录实际实现、验证结果、遗留问题与交接状态；`AGENTS.md`承载开发及验证约束。小版本自动验证与总结、大版本末人工认证等约束应放入AGENTS，本文件不声称它们已写入仓库。本次仅生成本基线，不虚构HANDOFF进度或修改未知项目仓库。

核心模式为单人／双人合作PVE，最终目标上架Steam。每个任务暂定15分钟；首个任务为据点防守，敌军完全占领即失败，坚持到结束未完全失守即胜利，不要求清敌。首版一个阵营、两个专精、一张地图，具体波次暂跳过。叛军复用既有单位，虫族与机器人为未来方向。全体系规划步兵、装甲、快速及未来空军专精，航空尚未启用，但基础弹丸设计须兼容空对空导弹与投弹。

## 1 阵营专精与单位分类

### 三层配置

阵营决定整体军备风格，例如步兵大编制、性价比装甲或丰富火炮。专精决定作战方向和可用单位池；同阵营选择两个专精，合并单位池及类别预算。不同阵营均应有定位类似的专精，但装备和实现方式保留阵营特点。

| 专精 | 作战定位 | 典型装备 |

| --- | --- | --- |

| 步兵 | 大量步兵班组为主 | 中速中甲步战车，可提供步兵弹药补给 |

| 装甲 | 中速重甲为主 | 各型坦克，少量步兵及慢速装甲运输车 |

| 快速 | 高速轻甲为主 | 高速轻型车辆，适中步兵 |

| 空军 | 航空作战方向 | 后续随航空系统启用 |

每个专精保留基础反人、反甲、防空、侦察和补给手段；优势领域提供更多高级单位与配置。班组人数主要由阵营和单位配置决定，专精通过卡种、价格及允许在场数量体现区别。

### 按实际作战环境分为五类

| 类别 | 范围 |

| --- | --- |

| 侦查 | 以高视野获取情报的班组和车辆 |

| 步兵 | 作战步兵及主要伴随步兵的步战车、运载车 |

| 装甲 | 坦克和以独立地面直接交战为主的车辆 |

| 支援 | 炮兵、防空导弹、高炮、步兵迫击炮及后方运输补给 |

| 飞机 | 航空单位，暂不启用，额度为0 |

分类决定预算，单位类型决定伤亡和运输规则。步兵迫击炮属于支援预算、步兵类型；架设火炮属于支援预算、架设火炮类型。是否拥有车辆底盘不决定编组类别。支援不常上前线是定位，不是移动禁令。

## 2 作战群预算与单位卡

### 价值分预算

每个专精的五类额度合计3000，当前飞机额度为0，其余四类合计3000。两个同阵营专精的同类额度相加，总计6000。每类支出最多达到该类合并额度的110%，所有常规卡总支出不得超过6000；零额度仍为零，不强迫凑满预算。

卡片支出＝所选配置价值分单价×玩家选定最大在场数量。单位配置固定归类，不由玩家自行更改。同一型号不同配置各算一个卡种；常规卡种共用上限，具体数目待定。每卡独立限制在场数量，不另设全军在场总量上限，也不限制整局累计购买数量。

### 关联组卡

先选择步兵，再可关联步战车或运载车；卡车也可关联架设火炮，补给是运输单位的通用关联选择。主单位和关联单位合计价值后计入所属类别，关联仅用于组卡界面，不永久绑定局内对象。局内各组成单位可分别购买、指挥和补购，各自检查名额。

相同型号相同配置在两个专精中重复出现时，单位池去重，不重复叠加携带上限。具体关联组合的兵牌呈现与分项数量配置还需在组卡界面落地。

### 实验性武器

仅PVE启用，从所选阵营两个专精对应的候选池中选择一张实验卡、一种配置，战前锁定。实验卡独立一类，不占常规卡种名额或常规6000预算。价值单价×选定最大在场数量不得超过1000，不享受110%浮动；只用于平衡携带数量，局内仍支付独立出动费用。

实验单位强化专精与阵营特色，常规单位池在关闭实验单位后仍能完成基础作战。单位损失后可重新购买，不设整局购买次数。

## 3 出动分维护与退款

| 参数 | 数值或规则 |

| --- | --- |

| 初始出动分 | 1000 |

| 基础收入 | 每分钟300，每5秒到账25 |

| 地面维护 | 在场单位本体出动分的5%每分钟 |

| 空军维护 | 在场单位本体出动分的2.5%每分钟 |

| 结算周期 | 5秒；每次维护为每分钟费用除以12 |

| 补给购买 | 10出动分每1t；不计维护费 |

| 精度 | 内部浮点计算，界面整数去尾 |

单位价值分与本体出动分独立配置，均必须为非负整数且为 5 的倍数；配置与服务器明确拒绝非法值，不自动取整。维护费、退款及账户累计仍允许浮点计算，此整数约束不扩展到这些计算结果。价值分与出动分独立定价，6000价值分作战群的全部部署费用不必是6000。收入与维护同时结算；净支出扣存款，余额最低0，无负债。无法支付维护不使现有单位损血、消失或失去作战能力；购买必须余额足够。撤离人员不免维护费。

### 退款

B返回基地退款区域，到达后移除单位，释放名额。退款＝max[0，（单位出动分－当前缺失弹药对应费用）×0.1]。残编、生命值与模块损伤不影响退款；具体弹药费用与补给类型后续设置。正常退款不计击杀或死亡价值，单独记录金额。

返回途中仍可被击杀且收维护费；其他任务指令取消返基地任务。运输车与自己的车内单位可共同移除，各自计算退款后相加；剩余车载补给不额外退款。移速为0火炮须乘车返回，可随运输单位退款。

主动放弃不继承原装备弹药缺额到撤离人员，撤离人员仅按自身数值及弹药状态退款。出动订单生成前取消整单全额退款，包括补给。

### 价值统计

价值分既用于组卡，也等于正常击杀与死亡统计分值。价值KD＝累计击杀价值÷累计死亡价值；死亡价值0显示“无损”，不显示单位数量KD。班组全灭一次性结算整班价值，单兵伤亡不单独得分；补员不改变价值。最后造成消灭的单位获得击杀，其他参与者记录助攻，不额外产生价值分。

## 4 购买兵牌与出动订单

购买入口为单位类型列表→具体单位列表。单位选定后选择出行方式；运输载具选定后选择乘客和补给吨位，可空载。出行方式决定自行移动或搭乘载具；载具与乘客必须来自已编入作战群的配置。移速为0的架设火炮必须绑定卡车出动。

确认购买即扣除各组成单位及补给费用，分别预留对应名额。同一组合订单使用一张兵牌。已有在场数量＋待生成订单数量不能超过每卡选定上限。手持未放置兵牌也占名额，尚未生成不收维护费。

| 步骤 | 操作 |

| --- | --- |

| 购买后 | 显示有辨识度的兵牌，跟随鼠标 |

| 放置 | 左键地图指定目的地，开始生成读秒 |

| 调整 | 第一次左键点击兵牌拿起，中止读秒；第二次左键放下，重新完整读秒 |

| 取消 | 手持时右键或E取消；读秒中右键点击兵牌取消；全额退款并释放名额 |

| 生成 | 地面3秒，空军6秒；出生点生成，前往兵牌位置 |

同时只能拿起一张兵牌，多张已放置订单并行读秒。兵牌不是实体单位，不侦察、占点或受攻击；无效位置禁用符号提示，不使用红色区分无效与攻击。兵牌用单位形象、配置符号与短名称体现差异。

### 出生与默认行为

当前使用固定地面通用出生点，后续任务可加限定种类入口和独立空军入口。局外设置出场基本移动或快速移动，以及到达后卸载或保持搭载。生成时乘客已搭载，维护从生成后开始。

到达卸载只在目的地执行，途中遇敌不自动卸载；空间不足保持搭载并提示。修改出动移动命令取消原地自动卸载安排；卸载后载具留在原地。到场前取消指生成前取消，不包括生成后的赶路阶段。

## 5 运输容量与装卸

关联单位局内不永久绑定，可分别购买。运输资格仅检查最大乘员与重量，不另加可运输类型标签。步兵按满编人数占座，重量＝满编人数×0.1t＋特殊装备重量；伤亡与弹药消耗不降低占用，撤离人员同样适用。

### 独立容量和单向借用

运输单位分别设置最大乘员、专用运输载重和补给容量。补给不能占用专用运输载重；步兵与特殊装备可侵占补给容量。人数始终受最大乘员硬限制。

设专用运输载重W、补给容量S、所载单位重量C，则须C≤W+S，补给量≤S−max(0,C−W)。装载完成时自动丢弃被挤占的补给，不退款、不生成地面堆、不计敌方击杀分。例：W=1t、S=1t、乘客装备1.2t，则最多携带0.8t补给。

### 装卸行为

装载采用选单位后右键运输车；双方靠近停车。不能自行移动的火炮由车辆靠近装载；失能步兵仍可低速登车。装卸时间按待载单位配置独立设置，步兵较快、火炮车辆较慢，不增加火炮架设时间。

装卸期间双方不能移动或射击，仅受攻击不中断。装载完成前单位在车外，卸载完成前仍在车内，完成才切换状态。移动或取消会清零进度并保留原位置；开始装载预留容量，完成才丢弃挤占补给。多单位按兵牌顺序执行，不拆班，容量不够跳过并提示。装卸不消耗补给。

### 运输损失

车内单位不能射击或成为单独攻击目标。运输车被毁时，普通步兵强制卸载，每名士兵受固定伤害、班组增加固定压制且至少恐慌；达到失能阈值则失能。不再叠加摧毁车辆的同一次攻击伤害。伤害与压制值待定。车载补给全部损失，不殉爆。所载火炮和车辆直接摧毁，撤离人员生成见下一节。

## 6 主动放弃与撤离人员

统一名称“撤离人员”，视作一种普通步兵，只能由撤离事件生成，不能直接购买。不重新操作装备，可治疗补员、运输、自卫与退款，武器为阵营对应PDW，属于正常枪械，数值偏低。

| 事件 | 人员生成 | 原装备计分 |

| --- | --- | --- |

| 地面装备正常被击毁 | 不生成 | 全额价值 |

| 所载火炮或车辆随运输车摧毁 | 每个被运输单位独立50%概率生成 | 全额价值 |

| 飞机被击毁 | 50%概率跳伞生成 | 全额价值 |

| 主动放弃或主动跳伞 | 完成放弃后生成 | 少量价值，比例待定 |

| 飞机燃油耗尽 | 自动按主动放弃处理并生成 | 少量价值 |

运输车本身不因正常被毁生成撤离人员。普通步兵乘客强制卸载使用运输伤亡规则，不使用50%抽样。

### 主动操作

主动放弃需要二次确认，再读条3秒；地面单位期间不能移动，仍可被正常击毁。读条内被毁按正常摧毁，不重复生成。燃油耗尽自动触发，无需确认，具体航空动作待航空系统细化。

主动放弃击杀者显示“本单位／自身”，对方队伍获得少量价值；被动逃生不减少原装备击杀分。撤离人员再次被击杀仅按自身低价值分结算。

### 名额与退款

原装备消失立即释放原卡名额，撤离人员不继承名额、不占卡种名额。人员生成即恐慌，出动分与原单位相当且正常计维护。返回基地用普通退款流程，金额按自身出动分和自身弹药缺额计算；人数损失不降低固定配置出动分。全员阵亡无退款。

## 7 补给来源与服务

补给只在出生点随部署购买，玩家自选吨位，10出动分每t；不能在场上生产，也没有基地免费补充。通过现有库存转运持续供给。

| 运输子标签 | 车载服务 | 库存装卸 |

| --- | --- | --- |

| 移动补给 | 作为移动补给点，为步兵补弹；不能治疗补员 | 可从地面点装载，不能卸下建点 |

| 建造补给点 | 车载库存不能直接服务 | 卸下才成为完整补给点；可从已有点装回运往他处 |

两标签互斥。移动补给车不参与地面堆合并。步兵专精补给步战车按此限制提供服务。

### 地面点与合并

地面点自动服务范围内己方及队友。新补给进入已有点范围时，移除原堆，在先存在的堆位置生成新堆，剩余库存相加，不扩大范围；运输单位不合并。装回地面库存受车辆补给容量及载重借用限制，库存耗尽点消失。无主动销毁补给操作。

### 服务条件

受补单位停车且停止开火才接受服务，移动或开火暂停，仅受攻击不强制中断一般服务。移动补给双方需停车。车内乘员按车辆位置接受地面点服务，移动补给可服务自身步兵乘客。恢复完成的效果保留，不重复扣费。

弹药补充和人员恢复并行，各项独立进行，不共享总补给速率但共享库存。每班组同一时刻只结算一次，不因来源重叠加速；来源耗尽自动切换。补给速度与范围按配置设置。车辆模块维修保留其受击中断与安全时间要求，见模块规则。

## 8 补给消耗与殉爆

| 项目 | 当前消耗 |

| --- | --- |

| 步兵治疗 | 0.025t每恢复1生命 |

| 补员 | 0.2t每人，补入生命5 |

| 模块维修 | 0.25t每修复一个损伤等级 |

| 车辆生命值恢复 | 待定 |

| 弹药与烟雾 | 具体类型和吨位待定 |

模块维修按损伤等级计费。人员补给顺序为补员→治疗；失能自动解除，不单独消耗补给。弹药独立并行。完成一次扣一次，库存不足暂停该项，其他较小费用可继续；同刻争库存按开始接受补给顺序处理，不出现负库存。

### 地面补给点属性

补给点可被攻击，不提供侦察，不占点；生命值和服务范围待数值配置。被摧毁按剩余吨位×10计入价值损失和敌方击杀价值。车载库存损失与本体价值分开记录，补给不参与维护。

### 殉爆

只有地面补给点被毁且剩余库存≥1t才殉爆，少于1t不触发；车载库存不殉爆。伤害＝伤害系数×剩余吨位。半径＝范围系数×剩余吨位，再限制在最小与最大半径内，系数及上下限待定。

殉爆带特效，按既有爆炸距离衰减与防护处理，步兵按人员位置受伤与压制。伤害双方单位，可引爆附近其他补给点；每点只触发一次。连锁击杀归最初引爆的攻击单位；友军损失计死亡价值，不增加攻击方击杀价值。

## 9 生命伤亡与压制

每名步兵最大生命5，独立计伤，显示班组总生命与人数；全班归零直接消灭，不设额外濒死。直射命中选择一名存活士兵，超额不溢出；爆炸按个人逻辑位置分别结算。单兵残血不额外降低效率。

### 武器接替

士兵阵亡移除其武器与携带弹药，特殊武器优先由幸存人员自动接替，接替者原主武器停止使用。按配置优先级和最低操作人数保留武器，不生成拾取物。补员恢复原岗位，不凭空补满整个班组弹药。

### 压制状态

各武器有独立压制值、破坏值。有效近爆及未击穿命中可压制，一次爆炸对班组只计一次压制。Q<S正常，S≤Q<2S恐慌，Q≥2S失能；单次攻击可跨阈值。恐慌视野减半，瞄准与装填时间翻倍。

有效命中或近爆刷新安全恢复时间，含零伤害命中；仅被瞄准不刷新。一段时间未受新增压制后，压制自然下降；低于失能阈值自动解除压制失能，按当前压制值判断恐慌或正常。等待时间及下降速度待定。存活人数≤满编人数10%时触发伤亡失能，补员超过该线后自动解除，不额外取整。两种原因同时存在时，须均不满足失能条件才解除。10人班剩1人失能，8人班剩1人不因人数失能。

### 失能与冲刺

恐慌移速为基础速度50%，失能为25%，不叠加。失能仍允许移动、撤退和登车，禁止射击瞄准，装填暂停保留进度，其他主动交互限制保持。瞄准清零，装卸清零；任务队列保留可修改，E可清空。烟雾和冲刺不受状态限制，解除后按压制值判断状态。

冲刺按Z立即给予固定移速增量和持续时间，不另选点。无移动任务则留原地，移速按基础速度×状态倍率＋固定冲刺增速计算，结束后恢复当前状态移速。期间禁瞄准射击，可烟雾；火炮班组禁冲刺。冲刺单位暂退出队形限速，结束后恢复；增益不叠加不刷新，冷却从开始计。具体参数待定。

## 10 防护弹道与装甲模块

动能与化学能防护均≥10，按命中方向取装甲，步兵两类防护相等。生命归零直接摧毁。P为距离下穿深或破深，A为对应防护，D₀为标伤。

### 动能

P≤0.5A：D=0；0.5A<P<A：D=D₀×P/A；P≥A：D=D₀。穿深按距离对数衰减，参数待定。P≥A才为击穿，部分扣血不算击穿。

### 化学能

P≤0.1A：D=0；0.1A<P<10A：D=D₀×P²/(P²+A²)；P≥10A：D=D₀。破深不随飞行距离衰减。迫击炮按化学能与曲射范围伤害，先距离衰减标伤再防护减伤，范围函数待定。

| 模块 | 轻伤 | 重伤 |

| --- | --- | --- |

| 观察 | 视野1/2 | 视野1/4 |

| 瞄准 | 时间×2 | 时间×4 |

| 人工装填 | 时间×2 | 时间×4 |

| 自动装填 | 时间×2 | 停止装填，待发弹可射 |

| 引擎 | 移速1/2 | 无法移动 |

仅击穿累计模块破坏，每满阈值T从未重伤模块随机升级一级，扣阈值保余量；单击可多次，四模块正常到全重伤共8次即8T。全重伤后余量与维修后量表处理待定。满生命不消除模块伤。自动装填重伤中断，修复后从零装填。

维修优先引擎→满生命→装填→瞄准→观察，获得资源的模块可并行。须停车停火，命中或有效近爆中断未完成计时，安全后重来；完成扣费，已修保留。

弹药及装甲有碰撞体积，步兵班组共用碰撞体并保留个人逻辑位置。APS可选，全向简化，资格按武器类型，次数冷却型号独立；其他参数待定。

## 11 移动队形与任务队列

| 指令 | 行为 | 路径 |

| --- | --- | --- |

| 基本移动 | 避障外尽量直线，不主动停车接敌 | 蓝色虚线 |

| 快速移动 | 按预计到达时间选路，不增加基础速度 | 绿色虚线 |

| 攻击移动 | 遇有效目标停车交战，结束继续原路线，不追击 | 红色虚线 |

| 倒车 | 装甲适用，保持车头，独立倒车速度 | 黄色虚线 |

硬化与非硬化路面影响装甲速度，步兵同速。无武器不能攻击移动，步兵不能倒车。路径选中才显示；后续任务虚线和编号，当前与后续均虚线。无效目标禁用符号，火炮准星、移动箭头。

### 局外移动设置

可选按组内最慢有效速度保持队形，或按各自速度。仅本次移动组参与，随地形与移动方式动态计算；乘客按载具，不可移动单位提示并排除。目的地分配不同落点。攻击移动交战单位退出速度协调，其他继续；独立新命令退出组。

避障优先，可暂打破队形，通过后恢复；快速移动仍各自选快路，不强迫同一路线。冲刺暂不受最慢速度限制。

### 任务队列

Shift追加，不按Shift替换并清空后续。各单位独立执行，移动到达、装卸完成、指定目标摧毁视为完成。持续攻击地面无结束条件，会阻塞后续。无法执行且目标已失效跳过提示；暂缺弹或空间不足等待。即时烟雾冲刺不入队不覆盖任务。

E在交互状态先退出交互，无交互则取消任务清队列；不启用被关闭武器、不关闭仅还击。H不清队列。混选资格分别检查，不支持单位保留原任务；运输车与车内乘客同选只执行车的移动。

## 12 视野目标与开火

单位独立视野，侦察更高，具体数值后定。地形遮挡，暂不加隐蔽值或探测概率；同队共享视野。补给点无视野，乘客不额外提供视野。敌离开后灰色最后位置不更新生命位置；照亮旧位置未发现即清标记，不可直接单位攻击，可强制攻击地面。命中反馈统一处理，不另设强制攻击专用反馈规则。

### 选敌与接近

手动目标优先。局外自动策略选最近或最高伤害效率，后者按经防护预计有效伤害比较，不按价值分；同效率选最近。各武器独立，只选可见、射程内及路径有效目标；已有目标保持到失效，不因更优敌人出现反复切换。

局外接近策略选最长武器可开火或全部适用武器可开火。只计启用、有弹且能攻击该目标的武器，PDW正常参与。接近是初次开火准备，不是追击；到位后目标出射程不跟随，所有攻击都不追击。恢复短射程武器不再次前进。目标失视停止指定攻击并执行后续队列。

### 火炮与路径

火炮不自动开火，只接受T；目标超射程可初次接近最大射程，移速0无法自行接近。单点实际弹道有障碍则拒绝；区域模式按第19节逐目标或落点检查。不自动找绕障射击点。直射须无遮挡，间接可越障但检查实际弹道。地面目标可不可见。火炮无射界限制、无架设撤收时间，转向仅动画，统一瞄准时间远长于转向动画。

普通共用炮塔主炮和同轴共享朝向，独立站自行转向。手动目标优先定炮塔方向，自动主武器优先；普通炮塔转速与开火就绪细节待定。

### 仅还击

H开启后受伤害或压制前全部武器禁止开火，不积累瞄准或自动接近。受击解锁当前范围目标，安全一段时间重锁，受击刷新计时；时长待定。手动任务不绕过限制，火炮仍需T。H重启清触发，关闭不启用停用武器。

## 13 武器瞄准弹药与烟雾

每把武器独立移动射击资格、瞄准、装填，可同时射击不同目标。开火须武器启用、状态允许、弹药足够、目标有效、仅还击许可；火炮另需命令。信息面板可统一启停同型号武器，任何新指令不改变开关。

### 瞄准与装填

持续同目标瞄准一次后按射速装填连续射击；换目标或失视清瞄准。禁移动射击武器移动清零，支持者可移动瞄准。停用、失能、冲刺清瞄准，恐慌使用时间惩罚。瞄准与装填并行，两者完成才开火。

区分待发与备用，装填从备用取弹；补给只加备用，不缩装填。换目标失视停攻击不重置装填，停用仍可装填；失能暂停保进度，待发弹不丢。自动装弹机重伤中断后修复重来。弹匣齐射容量独立配置。

部分缺弹其他继续，全缺弹不自行找补给。手动攻击保留等待，补弹重新瞄准但不接近；攻击移动缺弹继续路线；火炮等待。目标灭完成，失视结束指定目标任务。

### 烟雾

X步兵车辆在自身位置释放，无投掷选点，不覆盖任务。失能与恐慌可用。烟雾遮断双方观察不挡实体和弹丸，其他友军有视野可保持目标可见；射手烟雾遮挡停止自动直射，可强制打地面；间接地面任务不取消。不直接解异常。

每单位独立库存和CD，成功扣弹开始冷却，补弹不重置CD，重叠各自计时不增强遮蔽。多选可用者释放、无库存冷却者跳过，共键冲突整组不执行。按钮显示CD条与可用数量，全部冷却显示最早恢复者；具体范围时长消耗后定。

## 14 兵牌面板与鼠标交互

单选屏幕下方显示兵牌、名称、总生命，步兵存活满编人数、武器和弹药。同型号武器合并数量，同种弹药合计，不同武器弹药分列；数量随伤亡变。进度不同显示就绪数与总数，瞄准装填分别表达。不显示视野隐蔽等细数值。

鼠标菜单提供适用的移动、倒车、攻击、装卸、返回、能力按钮；需目标则右键确认，即时能力点击执行。仅还击按钮亮开暗关、混合半亮。仅还击状态在己方兵牌旁显示，敌方不可见，单独单位信息不重复显示。

### 多选与快捷选择

每单位一兵牌附生命条及异常图标，搭载中图标，无悬停文字。排序侦查→步兵→装甲→支援→飞机，同类按配置且不因状态跳位，超宽横滚。多选武器区显示多单位，菜单取可用操作并集。

单击兵牌或Tab循环单单位，保留原集合，指令只对当前单位；Shift+Tab恢复集合。Tab按面板顺序，阵亡退出删去，当前死亡切下一。双击兵牌选屏幕内当前可控同型号同配置单位，不含订单。

### 消息与交互

所有文字提示除当前操作类型外进入左侧信息栏，无悬停文字；重复原因去重，同批合并，可定位单位、淡出并展开历史。失败尝试或重要状态变化提示，不在鼠标经过时弹。正常成功靠动画路径反馈。

普通左键选、拖框选、空地清空，Shift左键增减，Shift框选加入。指令选点右键确认、左键或E退出且不穿透选择；Esc只开菜单。手持兵牌左放右取消，E取消订单。界面点击不穿透。

## 16 合作权限与掉线撤退

队友单位仅能查看，不能操作；己方单位不能搭乘队友运输车。共享视野、共享补给及共享镭射标记保留。不存在任何控制权转移。

玩家掉线后，可移动单位自动执行返回出生点退款，途中正常受击并计维护费。车内单位随运输车撤退，到达后与载具分别退款，不先卸载。自身移速为0或发动机重伤导致不能移动的装备，自动触发主动放弃：无需人工确认，仍读条3秒且可被击毁；撤离人员生成后自动返基地。恐慌及失能步兵仍有移动能力，直接撤退，不因此触发放弃。

## 17 部署受阻

读秒结束在出生点范围寻找最近有效空位。无空位时等待部署，保留费用与预留名额，不收维护；有空位后直接生成，无需重新读秒。等待期间可拿起兵牌调整位置，放下重新完整读秒，取消全额退款。按读秒完成先后部署，但某个订单尺寸受阻不阻塞其他可部署订单。敌人接近不关闭出生点，新单位没有无敌保护。

已生成单位无法到达兵牌目的地时，前往最近可达位置并提示，不自动退款；卸载空间不足保持搭载。

## 18 弹丸、制导与友伤

### 基础弹道

仅两类基础弹道，制导为可选属性，不另设第三类：

| 类型 | 规则 | 适用范围 |
| --- | --- | --- |
| 直线型 | 按设定速度沿当前方向飞行，不计算重力 | 枪弹、机枪弹、坦克直射弹、直射火箭弹、各类导弹 |
| 抛物线型 | 初始速度及重力形成弧线 | 迫击炮弹、间接火炮弹、航空炸弹 |

弹丸参数包括速度、散布、最大飞行时间，以及适用时的重力、制导方式与转向速度。航空炸弹继承投放瞬间飞机速度。暂不模拟空气阻力、风偏、燃料推力或分段加速，不加入跳弹或穿透多个单位。动能穿深按飞行距离计算衰减，不要求同步减速。

散布在发射时决定方向或落点，命中时不额外掷命中概率。直射武器按目标当前速度计算提前量；转向变速可能使弹丸落空。普通间接炮击瞄准发射时确定的位置，不预测远期移动。

### 独立存在与归属

弹丸由服务器生成，独立记录飞行状态、弹药类型和固定发射来源（发射单位身份、所属玩家）。来源单位死亡、退款或改命令不取消已发射弹丸，击杀仍显示原发射单位并归原玩家。此处是规则归属要求，不指定程序类结构。

实际碰撞决定命中，首先碰撞有效对象后结算并消失；爆炸在实际碰撞位置发生。弹丸与地形、建筑及敌我单位碰撞。班组共用碰撞体，命中后的单兵伤亡仍按第9节结算。

### 友伤与开火检查

弹丸可被友军挡住，直击与爆炸都具有友伤，爆炸同时造成压制。生成时排除发射单位自身避免炮口自碰，后续爆炸仍可伤及发射单位。

直射自动开火及普通指定攻击在发射前检查友军遮挡；被挡则暂缓，不绕路、不追击。发射后友军进入弹道仍可中弹。G强制攻击跳过友军遮挡检查；火炮手动炮击不因落点附近有友军而拒绝。地形障碍规则仍有效。

误伤击杀显示实际发射单位并标注友军误伤，受害玩家记录死亡价值；射击方无击杀价值，不额外扣出动分。补给殉爆连锁沿用最初引爆者归属。

### 制导共性

制导只修正飞行方向，不改变弹药本身伤害、穿深与爆炸范围。转向速度有限，不能瞬间折角、穿越地形，激活不保证命中。空对空导弹采用直线基础弹道及其独立锁定／制导规则；不能把镭射永久失锁规则直接套给所有导弹。空对空锁定与干扰物细则待定。

## 19 火炮T菜单与炮击任务

火炮和迫击炮仅通过T命令开火，使用同一套二级菜单，覆盖原鼠标菜单区域。T与未来导弹精确打击、飞机精确投弹沿用共键互斥规则。

| 弹种 | 默认 | 烟雾 | 制导 |
| --- | --- | --- | --- |
| 范围模式 | 单点 | 跟踪 | 徐进 |
| 射击数量 | 一发 | 三发 | 全弹 |

每行单选并高亮。未携带弹种不显示对应按钮，位置留空，不移动其他按钮；已携带但耗尽保留置灰。多选显示弹种合集，命令只由携带对应弹种的单位执行，其他跳过并汇总提示。默认指该配置常规炮弹，不自动切烟雾或制导。制导不禁用任何范围模式。

局外设置默认三行选项，以及下次任务沿用上次选项或恢复默认。打开菜单与调整选项不影响当前任务；右键确认地图目标才替换或Shift追加。E只退出菜单交互。每项任务保存确认时设置，之后改菜单不改变已有任务。

### 单点／跟踪／徐进

单点攻击固定位置。目标超射程初次移动至最大射程，移速0无法接近则拒绝；弹道阻挡拒绝，不另找阵地。

跟踪以右键拖出圆形区域、松开确认，区域半径上下限待定。每次发射前从区域内被点亮或有最后已知位置的敌人选目标，优先当前可见，其次最后已知，同级轮流分配。当前可见用最新位置，失视用最后已知，不获取隐藏真实位置。可见目标离开区域后不再攻击；旧位置重新照亮且确认无目标时清记录。区域无目标则等待，不自动跳下一队列任务。

跟踪以中心点作为首次接近依据，进入其最大射程后停下，仅选区域内且在自身射程内目标，不继续追击。多炮尽量分配不同目标，目标少时允许重复；每次检查实际弹道，受阻目标跳过。

徐进以右键从起点拖到终点确认，红色虚线显示方向。沿线推进，不要求目标可见，不因发现敌人偏离。一发射起点；三发射起点／中点／终点；全弹按本次数量均匀覆盖全线。多门炮各自走完整路线，不互等。首次接近须使全线均处于射程内，找不到可执行位置则拒绝并提示。受阻落点跳过，不耗弹不计已发射次数；到路线终点结束，取消未完成轮数，不自动重复。

烟雾沿用相同落点规则，不判断己方掩护需求。徐进不会自动生成或移动镭射标记，只有靠近实际有效标记的炮弹可能制导。

### 数量与打断

一发／三发按每门炮计算；四门三发共十二发。跟踪数量是每门炮整个任务的预算，不是每个目标各打一轮。全弹取每门炮开始执行时所选弹种现有弹药总量，途中补给不追加。三发不足则打完现有弹药结束并提示。各炮独立瞄准装填完成任务，不强制齐射。

普通移动、快速移动、倒车、新炮击命令替换当前炮击任务并取消剩余数量；Shift追加在任务完成后执行。已发炮弹继续，制导独立有效。移动清瞄准，装填沿用武器规则；停止后不恢复已替换任务。跟踪等待可通过E取消，E清队列规则不变。

现行火炮采用统一瞄准时间，转向仅动画、无架设撤收及射界限制；不新增落点调整时间，相关最新建议尚未确认。

## 20 镭射指示

### 命令与照射资格

携带设备单位按Y后右键敌方单位或地面位置。单位标记随可见目标移动，地面标记位置固定。每套设备一个标记，新任务替换旧任务。多选有设备者执行，无设备者忽略。

镭射是普通任务：直接下达打断移动并停车；Shift加入队列，前项完成后执行。新普通命令替换后停止照射。选目标交互中E只退出交互，其他情况下E清任务并停止照射。

所有设备移动中不能照射。步兵照射距离2000米，载具3000米。与武器独立，其他武器可以正常开火，仅还击不限制照射。恐慌不直接中断；失能、搭载或单位被毁中断。失能解除后可继续当前照射任务，搭载是否保存任务遵循后续运输命令与队列结果。

超距离、失视或地形烟雾遮挡时暂停照射并保留任务，不自动接近或追击。恢复有效条件后自动照射。单位目标被毁任务结束继续队列；地面目标持续直到取消或替换。炮弹命中不结束照射。镭射不增加视野，不揭示周围敌人。地面点可照射但必须满足距离和遮挡条件。

### 标签与表现

| 状态或特效 | 规则 | 可见性 |
| --- | --- | --- |
| 被镭射标记标签 | 仅有效照射时用于引导判断 | 仅服务器，不向玩家显示标签 |
| 绿色照射实线 | 照射者连接单位目标或地面点，受阻消失 | 照射者所属玩家 |
| 绿色兵牌状态指示器 | 正在有效照射 | 照射者所属玩家 |
| 黄色兵牌状态指示器 | 任务仍在，但暂不能照射 | 照射者所属玩家 |
| 红色引导实线 | 已激活引导的炮弹连接其标记目标 | 所有人 |

取消照射移除绿线和指示器。红线不提供点亮、兵牌或实时信息，但几何连线会暴露引导目标当时位置。文字提示仍只在左侧信息栏，不增加悬停提示。

### 激活与失锁

制导弹药不要求发射时已有照射，先按基础弹道飞向预定落点。进入单位目标或固定地面标记的三维距离100米内，发现有效己方或队友标记才激活。始终未激活则按普通弹道散布结算。

多个候选优先本次明确指定目标，否则选距预定落点最近的有效标记。锁定后不换目标。地面标记不吸附附近单位，也不给其增加标签。

引导期间持续修正；最后一条有效照射中断或目标被毁，红线消失，永久失锁，飞向最后一次有效引导确定的位置，仍检查碰撞，不保证命中移动目标。恢复照射不能让已失锁炮弹复锁，只能服务尚未锁定的新炮弹。换照射目标结束旧标记，已锁定旧标记的炮弹不会随之切换。

多名己方或队友同时照射同目标时，一条中断不影响其他有效照射；各照射者指示器独立变化。标记不消耗，可供多枚弹丸使用；不叠加精度伤害或激活距离。击杀归射击单位，照射者不额外得击杀价值。

## 21 后续PVP专用规则

两阶段各10分钟，只用于结算；20分钟按双方累计总分判断，同分加5分钟。占领和击杀分别推进独立量表，同等重要，兑换系数待定。阶段将所有累计值直接折算含未满部分，清空进度，不重置战场状态。加时仍同分的处理及精度容差待定。

占领量表按比对手多占点数增长：v×max(己方点数−敌方点数,0)，不扣历史分。据点敌方／中立／己方三态，先清敌再填己，固定速度；有单位即可推进，状态和数量不影响速度，双方在点暂停，无人保进度。补给点不能占点。

消灭按配置价值，单兵伤亡、失能、模块伤不单独计分；补给毁损10分/t。主动放弃只给对方少量价值，自身为击杀者；正常被动逃生不降低原装备价值。占领和击杀不直接产生出动收入。
