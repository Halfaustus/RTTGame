基线标识：DB-2026-10-04-21。状态：已确认规则汇编。日期：2026-10-04（北京时间）。目标路径：`docs/DESIGN_BASELINE.md`。

## 0 文档职责与范围

本文件是游戏设计的唯一现行基线，规定游戏应怎样运行，不代表任何功能已经实现。来源为《RTT项目计划书_v3》及本会话截至本次请求的已确认修订。v3保留为历史项目书，不作为冲突时的第二套现行规则。其他会话未完整提供的设计不推断补齐；跨会话文档发生冲突须明确报告，确认后更新正文。

每批设计讨论结束整理新增／替换／删除／待定四类变更；已确认变化直接更新本文件正文。历史版本与被替换规则不留在本基线正文，统一隔离至 `docs/DESIGN_HISTORY.md` 追踪。待定项不作为已批准开发要求。提示词仅指定本轮范围及新增变化，不复制整套规则形成另一份基线。

`HANDOFF.md`仅记录实际实现、验证结果、遗留问题与交接状态；`AGENTS.md`承载开发及验证约束。小版本自动验证与总结、大版本末人工认证等约束应放入AGENTS，本文件不声称它们已写入仓库。本次仅生成本基线，不虚构HANDOFF进度或修改未知项目仓库。

### 规则优先级与冲突记录

当基线内部出现表述冲突时，优先级依次为：用户最新明确确认的正式规则与框架 ＞ 针对该规则明确声明的特殊例外 ＞ 临时测试值 ＞ 待定事项。临时测试值只能填补尚未确定的实例参数，不得覆盖或修改正式框架；待定事项不得反向覆盖已经确认的正式规则。

一旦出现冲突，须在第22节“待定事项与冲突登记”中记录产生冲突的原因和具体情况，包括相互冲突的条款、适用范围、按上述优先级采用的处理口径及尚需用户确认的部分。按优先级处理不免除记录义务；不得以解释冲突为由自行修改框架。

### 开发期测试单位自主设计授权

自 DB-2026-10-04-21 起，除非用户后续明确撤销、禁止或收窄授权，允许Codex在用户现有已定义框架内自主创建任何类型的测试单位、武器班组与测试配置，无需逐个取得批准。可在框架允许的字段、范围与规则内配置人数、防护、岗位、武器、弹药以及射程、伤害、穿深、压制、散布、瞄准、射速、装填等尚未确定的实例参数。

严禁Codex自行修改、扩展、删除或重新解释用户已经定义的框架，包括单位与武器属性体系、伤害公式、运输规则、能力标签类别、武器槽位及其他已确认机制；不得以测试需要或本授权为由覆盖已有正式规则、通用数值及独立武器的已确认性能。明确标注“仅供测试”的对象可在同一框架内调整或移除。

所有自主创建且尚未经用户正式确认的对象须在数据、文档、原型／交接记录或测试界面中以足以识别的方式标注“仅供测试”。实现、反复使用或通过验证不使测试对象自动成为正式单位或平衡结论；正式版清理时可移除，只有用户明确确认后才能转为正式设计。

具体正式单位实例已移出本基线；本文件保留通用系统框架、机制、字段与独立武器规则，不要求恢复任何历史单位配置。

核心模式为单人／双人合作PVE，最终目标上架Steam。每个任务暂定15分钟；首个任务为据点防守，敌军完全占领即失败，坚持到结束未完全失守即胜利，不要求清敌。首版一个阵营、两个专精、一张地图，具体波次暂跳过。叛军复用既有单位，虫族与机器人为未来方向。全体系规划步兵、装甲、快速及未来空军专精，航空尚未启用，但基础弹丸设计须兼容空对空导弹与投弹。

## 1 阵营专精与单位分类

### 阵营与专精配置

阵营决定整体军备风格，例如步兵大编制、性价比装甲或丰富火炮。专精决定作战方向和可用单位池；同阵营选择两个专精，合并单位池及类别预算。不同阵营均应有定位类似的专精，但装备和实现方式保留阵营特点。

| 专精 | 作战定位 | 典型装备 |
| --- | --- | --- |
| 步兵 | 大量步兵班组为主 | 中速中甲步战车，可提供步兵弹药补给 |
| 装甲 | 中速重甲为主 | 各型坦克，少量步兵及慢速装甲运输车 |
| 快速 | 高速轻甲为主 | 高速轻型车辆，适中步兵 |
| 空军 | 航空作战方向 | 后续随航空系统启用 |

每个专精保留基础反人、反甲、防空、侦察和补给手段；优势领域提供更多高级单位与配置。班组人数主要由阵营和单位配置决定，专精通过卡种、价格及允许在场数量体现区别。

### 按实际作战环境分为五类

| 类别 | 范围 |
| --- | --- |
| 侦查 | 以高视野获取情报的班组和车辆 |
| 步兵 | 作战步兵及主要伴随步兵的步战车、运载车 |
| 装甲 | 坦克和以独立地面直接交战为主的车辆 |
| 支援 | 炮兵、防空导弹、高炮、步兵迫击炮及后方运输补给 |
| 飞机 | 航空单位，暂不启用，额度为0 |

分类决定预算，单位类型决定伤亡和运输规则。步兵迫击炮属于支援预算、步兵类型；所有架设火炮属于支援预算、步兵类型，统一为步兵班组＋特殊武器。是否拥有车辆底盘不决定编组类别。支援不常上前线是定位，不是移动禁令。

## 2 作战群预算与单位卡

### 价值分预算

每个专精的五类额度合计3000，当前飞机额度为0，其余四类合计3000。两个同阵营专精的同类额度相加，总计6000。每类支出最多达到该类合并额度的110%，所有常规卡总支出不得超过6000；零额度仍为零，不强迫凑满预算。

卡片支出＝所选配置价值分单价×玩家选定最大在场数量。单位配置固定归类，不由玩家自行更改。同一型号不同配置各算一个卡种；常规卡种共用上限，具体数目待定。每卡独立限制在场数量，不另设全军在场总量上限，也不限制整局累计购买数量。

### 关联组卡

先选择步兵，再可关联步战车或运载车；卡车也可关联架设火炮，补给是运输单位的通用关联选择。主单位和关联单位合计价值后计入所属类别，关联仅用于组卡界面，不永久绑定局内对象。局内各组成单位可分别购买、指挥和补购，各自检查名额。

相同型号相同配置在两个专精中重复出现时，单位池去重，不重复叠加携带上限。具体关联组合的配置呈现与分项数量配置还需在组卡界面落地。

## 3 出动分维护与退款

| 参数 | 数值或规则 |
| --- | --- |
| 初始出动分 | 1000 |
| 基础收入 | 每分钟300，每5秒到账25 |
| 地面维护 | 在场单位本体出动分的5%每分钟 |
| 空军维护 | 在场单位本体出动分的2.5%每分钟 |
| 结算周期 | 5秒；每次维护为每分钟费用除以12 |
| 补给购买 | 10出动分每1t；不计维护费 |
| 精度 | 内部浮点计算，界面整数去尾 |

单位配置的价值分与出动分独立配置，均须为非负整数且为5的倍数；非法值拒绝，不取整。维护费与退款允许小数计算。价值分与出动分独立定价，6000价值分作战群的全部部署费用不必是6000。收入与维护同时结算；净支出扣存款，余额最低0，无负债。无法支付维护不使现有单位损血、消失或失去作战能力；购买必须余额足够。撤离人员不免维护费。

### 退款

B返回基地退款区域，到达后移除单位，释放名额。退款＝max[0，（单位出动分－当前缺失弹药对应费用）×0.1]。残编、生命值与模块损伤不影响退款；具体弹药费用与补给类型后续设置。正常退款不计击杀或死亡价值，单独记录金额。

返回途中仍可被击杀且收维护费；其他任务指令取消返基地任务。运输车与自己的车内单位可共同移除，各自计算退款后相加；剩余车载补给不额外退款。移速为0火炮须乘车返回，可随运输单位退款。

主动放弃不继承原装备弹药缺额到撤离人员，撤离人员仅按自身数值及弹药状态退款。出动订单生成前取消整单全额退款，包括补给。

### 价值统计

价值分既用于组卡，也等于正常击杀与死亡统计分值。价值KD＝累计击杀价值÷累计死亡价值；死亡价值0显示“无损”，不显示单位数量KD。班组全灭一次性结算整班价值，单兵伤亡不单独得分；补员不改变价值。最后造成消灭的单位获得击杀，其他参与者记录助攻，不额外产生价值分。

## 4 购买与出动订单

购买入口为单位类型列表→具体单位列表。单位选定后选择出行方式；运输载具选定后选择乘客和补给吨位，可空载。出行方式决定自行移动或搭乘载具；载具与乘客必须来自已编入作战群的配置。移速为0的架设火炮必须绑定卡车出动。

确认购买即扣除各组成单位及补给费用，分别预留对应名额。已有在场数量＋待生成订单数量不能超过每卡选定上限。尚未生成的订单同样占名额，不收维护费。购买后生成一个暗化处理的兵牌作为订单位置指示；该暗化兵牌仅表示未来单位的目标位置，不是实际单位，不侦察、占点、受攻击或获得实际单位状态。其尺寸、单位识别图案和玩家颜色边框与对应实际兵牌完全一致，仅做暗化处理。组合订单仍使用一个订单位置指示，具体组合识别图案若需区别后续再定。

| 步骤 | 操作 |
| --- | --- |
| 购买后 | 生成暗化兵牌并跟随鼠标 |
| 放置 | 左键地图指定目的地，开始生成读秒 |
| 调整 | 第一次左键点击暗化兵牌拿起，中止读秒；第二次左键放下，重新完整读秒 |
| 取消 | 手持时右键或E取消；读秒中右键点击暗化兵牌取消；全额退款并释放名额 |
| 生成 | 地面3秒，空军6秒；出生点生成，前往暗化兵牌所指示的位置 |

同时只能拿起一个订单位置指示，多张已放置订单并行读秒。无效位置使用禁用符号提示，不使用红色区分无效与攻击。订单暗化兵牌只承担位置指示，不因其外观与实际兵牌相同而获得实际单位身份。

### 出生与默认行为

当前使用固定地面通用出生点，后续任务可加限定种类入口和独立空军入口。局外设置出场基本移动或快速移动，以及到达后卸载或保持搭载。生成时乘客已搭载，维护从生成后开始。

到达卸载只在目的地执行，途中遇敌不自动卸载；空间不足保持搭载并提示。修改出动移动命令取消原地自动卸载安排；卸载后载具留在原地。到场前取消指生成前取消，不包括生成后的赶路阶段。

## 5 运输容量与装卸

关联单位局内不永久绑定，可分别购买。运输资格仅检查最大乘员与重量，不另加可运输类型标签。步兵按满编人数占座，重量＝满编人数×0.1t＋特殊装备重量；伤亡与弹药消耗不降低占用，撤离人员同样适用。

### 总运输载重

运输单位设置“最大乘员数”和“总运输载重”。搭载人员、特殊装备及车载补给共用一个总载重池，任意组合的总重量均不得超过总运输载重；最大乘员数为独立硬限制，不因剩余载重充足而放宽。

设所载人员及特殊装备固定重量为C、现有补给重量为B、总运输载重为L，则须C+B≤L，并同时满足最大乘员数限制。人员按满编占位与固定重量计入，伤亡及弹药消耗不释放乘客占用；补给实际消耗降低补给重量并释放对应载重。具体单位若设置补给携带上限，该上限只限制补给数量，不形成独立或不可挪用的容量分区。

### 装卸行为

装载采用选单位后右键运输车；双方靠近停车。不能自行移动的火炮由车辆靠近装载；失能步兵仍可低速登车。装卸时间按待载单位配置独立设置，步兵较快、火炮车辆较慢，不增加火炮架设时间。

装卸期间双方不能移动或射击，仅受攻击不中断。恐慌和失能均不禁止步兵装载或卸载，不增加装卸时间；读条期间进入失能也不暂停或清零进度。卸载保留生命、人数及压制状态，搭乘不解除失能。装载完成前单位在车外，卸载完成前仍在车内，完成才切换状态。移动或取消会清零进度并保留原位置；开始装载预留容量，装载前须将现有补给计入总载重，容量不足则拒绝登车，不以自动丢弃补给腾出空间。多单位按单位条目顺序执行，不拆班，乘员位不足或重量超限时跳过并在右侧战场信息栏统一提示“载重不足”。装卸不消耗补给。

### 运输损失

车内单位不能射击或成为单独攻击目标。运输车被毁时，普通步兵强制卸载，每名士兵受固定伤害、班组增加固定压制且至少恐慌；达到失能阈值则失能。不再叠加摧毁车辆的同一次攻击伤害。伤害与压制值待定。车载补给全部损失，不殉爆。所有架设火炮班组沿用步兵乘客固定伤害与压制逃生规则，不再直接摧毁或50%生成撤离人员；所载车辆直接摧毁，撤离人员生成见下一节。

## 6 主动放弃与撤离人员

统一名称“撤离人员”，视作一种普通步兵，只能由撤离事件生成，不能直接购买。不重新操作装备，可治疗补员、运输、自卫与退款，武器为阵营对应PDW，属于正常枪械，数值偏低。

| 事件 | 人员生成 | 原装备计分 |
| --- | --- | --- |
| 地面装备正常被击毁 | 不生成 | 全额价值 |
| 所载车辆随运输车摧毁 | 每个被运输单位独立50%概率生成 | 全额价值 |
| 飞机被击毁 | 50%概率跳伞生成 | 全额价值 |
| 主动放弃或主动跳伞 | 完成放弃后生成 | 少量价值，比例待定 |
| 飞机燃油耗尽 | 自动按主动放弃处理并生成 | 少量价值 |

运输车本身不因正常被毁生成撤离人员。普通步兵乘客强制卸载使用运输伤亡规则，不使用50%抽样。

### 主动操作

主动放弃需要二次确认，再读条3秒；地面单位期间不能移动，仍可被正常击毁。读条内被毁按正常摧毁，不重复生成。燃油耗尽自动触发，无需确认，具体航空动作待航空系统细化。

主动放弃击杀者显示“本单位／自身”，对方队伍获得少量价值；被动逃生不减少原装备击杀分。撤离人员再次被击杀仅按自身低价值分结算。

### 名额与退款

原装备消失立即释放原卡名额，撤离人员不继承名额、不占卡种名额。人员生成即恐慌，出动分与原单位相当且正常计维护。返回基地用普通退款流程，金额按自身出动分和自身弹药缺额计算；人数损失不降低固定配置出动分。全员阵亡无退款。

## 7 补给来源与服务

补给只在出生点随部署购买，玩家自选吨位，10出动分每t；不能在场上生产，也没有基地免费补充。通过现有库存转运持续供给。

| 补给单位配置 | 车载服务 | 库存装卸 |
| --- | --- | --- |
| 移动补给 | 作为移动补给点，为步兵补弹；不能治疗补员 | 可从地面点装载，不能卸下建点 |
| 无移动补给标签（默认建点方式） | 车载库存不能直接服务 | 卸下才成为完整补给点；可从已有点装回运往他处 |

仅保留单位能力标签“移动补给”，取消“建造补给点”标签。具有补给能力而无移动补给标签的单位默认采用建点方式；普通单位不会因缺少标签获得补给能力。移动补给车不参与地面堆合并。步兵专精补给步战车按此限制提供服务。

### 地面点与合并

地面补给点保留队伍所属信息，不记录来源玩家；所属队伍各玩家均能正常使用，并由符合补给能力及移动补给标签规则的载具装载库存、转运和卸下建点，受容量限制。补给车仍有玩家归属和操作权限，只共用补给服务规则，不参与占领。

补给点采用敌方／中立／己方三态，沿用据点占领规则：先清敌再填己，固定速度，单位状态与数量不影响速度，双方在范围内暂停，无人保进度。量表缩短至近乎瞬间占领，具体时长待定。敌方须先占领才能使用或装载，占领不改变剩余库存。补给点不计任务据点数量，不推进PVP占领分；补给点自身不能作为占领单位。

只有同队补给点可自动合并。新点进入己方已有点范围，或中立／敌方点被占领后满足合并条件时，必须并入先创建的己方补给点；多个符合条件则选最早创建的己方点。被占领点自身的旧创建时间不能让已有己方点迁移。移除原点，在接收点位置形成总库存补给点，沿用接收点范围及创建顺序，不扩大范围。无符合条件点则独立保留。合并无退款、击杀、死亡或殉爆。运输单位不合并。库存耗尽点消失，无主动销毁补给操作。

### 服务条件

受补单位停车且停止开火才接受服务，移动或开火暂停，仅受攻击不强制中断一般服务。移动补给双方需停车。车内乘员按车辆位置接受地面点服务，移动补给可服务自身步兵乘客。恢复完成的效果保留，不重复扣费。

弹药补充和人员恢复并行，各项独立进行，不共享总补给速率但共享库存。每班组同一时刻只结算一次，不因来源重叠加速；来源耗尽自动切换。补给速度与范围按配置设置。车辆模块维修保留其受击中断与安全时间要求，见模块规则。

| --- | --- |
| 步兵治疗 | 0.025t每恢复1生命 |
| 补员 | 0.2t每人，补入生命5 |
| 模块维修 | 0.25t每修复一个损伤等级 |
| 车辆生命值恢复 | 待定 |
| 弹药与烟雾 | 具体类型和吨位待定 |

模块维修按损伤等级计费。人员补给顺序为补员→治疗；失能自动解除，不单独消耗补给。弹药独立并行。完成一次扣一次，库存不足暂停该项，其他较小费用可继续；同刻争库存按开始接受补给顺序处理，不出现负库存。

### 地面补给点属性

补给点可被攻击，不提供侦察，自身不占其他据点；生命值1，动能防护5，化学能防护5，按现有防护伤害公式结算；服务及占领范围待数值配置。摧毁敌方补给点按剩余吨位×10计入攻击方击杀价值和队伍补给损失，不计来源玩家个人死亡价值；摧毁己方或中立点无击杀价值，仍可能殉爆。车载库存损失与本体价值分开记录，补给不参与维护。

### 殉爆

只有地面补给点被毁且剩余库存≥1t才殉爆，少于1t不触发；车载库存不殉爆。伤害＝伤害系数×剩余吨位。半径＝范围系数×剩余吨位，再限制在最小与最大半径内，系数及上下限待定。

殉爆带特效，按既有爆炸距离衰减与防护处理，步兵按人员位置受伤与压制。伤害双方单位，可引爆附近其他补给点；每点只触发一次。连锁击杀归最初引爆的攻击单位；友军损失计死亡价值，不增加攻击方击杀价值。

## 9 生命伤亡与压制

每名步兵最大生命5，独立计伤，显示班组总生命与人数；全班归零直接消灭，不设额外濒死。直射命中选择一名存活士兵，超额不溢出；爆炸按个人逻辑位置分别结算。单兵残血不额外降低效率。

### 武器接替

士兵阵亡移除其武器与携带弹药，班组武器优先由幸存人员自动接替，接替者原主武器停止使用。按配置优先级和最低操作人数保留武器，不生成拾取物。补员恢复原岗位，不凭空补满整个班组弹药。

### 压制状态

各武器有独立压制值、破坏值。压制只适用于步兵类型（含架设火炮、迫击炮班组及撤离人员），车辆不积累步兵压制量表，但由人员状态模块获得恐慌／失能。设当前存活人数n、每人压制额度s、班组压制Q，则Q<ns正常，ns≤Q<2ns恐慌，Q≥2ns失能；全员死亡直接消灭，不进行零人数阈值判断。有效近爆及未击穿命中可压制，一次爆炸对班组只计一次，不按波及人数重复累计。单次攻击可跨阈值。步兵状态效果见下表；机械装填不受人员状态影响。

有效命中或近爆刷新安全恢复时间，含零伤害命中；仅被瞄准不刷新。一段时间未受新增压制后，压制自然下降；低于失能阈值自动解除压制失能，按当前压制值判断恐慌或正常。等待时间及下降速度待定。取消独立伤亡失能。阵亡只降低人数阈值，不额外增加压制；补员提高阈值。人数或压制变化后重新判断状态，低于失能阈值自动解除，不消耗额外补给。量表显示Q/(2ns)比例。每人压制额度s由具体单位配置确定，不由历史班组实例推定。

### 失能与冲刺

步兵失能不禁止开火、瞄准、装填或镭射，不暂停进度；装卸正常。状态只修改以下数值，不改变生命、防护、费用、重量或维护：

| 属性 | 平静 | 恐慌 | 失能 |
| --- | --- | --- | --- |
| 步兵移速、视野 | ×1 | ×1/2 | ×1/5 |
| 瞄准时间 | ×1 | ×2 | ×5 |
| 人工装填时间 | ×1 | ×2 | ×5 |
| 散布半径 | ×1 | ×2 | ×5 |
| 机械装填时间 | ×1 | 不受状态影响 | 不受状态影响 |

状态与模块变化保留瞄准／装填已完成比例，按新速度完成剩余进度，不清零或立即完成。已完成瞄准不因状态变化丢失。步兵各人员状态均无自身比例减伤，任务队列可修改。烟雾和冲刺正常可用。

冲刺按Z立即给予固定移速增量和持续时间，不另选点。无移动任务则留原地，移速按基础速度×状态倍率＋固定冲刺增速计算，结束后恢复当前状态移速。期间禁瞄准射击，可烟雾；火炮班组禁冲刺。冲刺单位暂退出队形限速，结束后恢复；增益不叠加不刷新，冷却从开始计。具体冲刺增速、持续时间及冷却按单位配置确定。

## 10 防护弹道与装甲模块

动能与化学能防护均≥5，所有弹药穿深与破深最低为5，按命中方向取装甲，步兵四个方向使用相同防护数值，动能／化学防护分别填写。生命归零直接摧毁。P为距离下穿深或破深，A为对应防护，D₀为标伤。

### 动能

P≤0.5A：D=0；0.5A<P<A：D=D₀×P/A；P≥A：D=D₀。穿深按距离对数衰减；PDW、普通步枪及同弹轻机枪的正式锚点见第24A节，具体函数参数仍待定。P≥A才为击穿，部分扣血不算击穿。

### 方向防护

车辆保留前／侧／后／顶四组动能和化学防护。按实际命中时车体朝向及弹丸来向判断，先判顶部：发射武器具攻顶标签或实际命中顶部时取顶部防护。其余按水平方向与车头夹角，≤60°正面、≥135°后方，中间为侧面，左右共用。不单设底部。

攻顶为武器标签，用于顶部防护结算；爬升俯冲的具体模拟待后续弹丸／制导讨论确认，不绕障、不保证命中、不自动加伤。近失爆炸按爆心相对车辆方向选防护面，先衰减伤害。一次攻击的同一爆炸对同车只结算一次：直接命中采用命中面，不再选择更弱的爆炸受击面重复结算。顶部可比后方更厚，不保证攻顶始终最优。

### 化学能

P≤0.1A：D=0；0.1A<P<10A：D=D₀×P²/(P²+A²)；P≥10A：D=D₀。破深不随飞行距离衰减。迫击炮按化学能与曲射范围伤害，先距离衰减标伤再防护减伤，范围函数待定。

| 模块 | 正常 | 轻度受损 | 重度受损 |
| --- | --- | --- | --- |
| 观瞄 | 正常 | 视野×1/2、瞄准时间×2 | 视野×1/5、瞄准时间×5 |
| 人员状态 | 平静 | 恐慌 | 失能 |
| 装填 | 正常 | 装填时间×2 | 装填时间×5 |
| 机动 | 正常 | 移速×1/2 | 移速×1/5 |

人员状态与其他模块同样由满足破坏资格的命中累计量表后随机升级及模块维修处理，无独立装甲压制量表。装甲恐慌／失能使瞄准时间与散布半径分别×2／×5，并使人工装填时间×2／×5；不另叠加视野或机动减速，后者由各自模块控制。

人工装填受人员状态及装填模块两者乘算影响；机械装填仅受装填模块影响，不被人员状态暂停。连射兵器未声明时默认人工换弹3秒，明确机械装填时基础时间为人工基础时间加1秒（当前4秒）；此默认规则不适用于非连射兵器。连射仅为设计分类，不增加游戏标签或分类字段。观瞄模块瞄准惩罚与人员状态瞄准惩罚乘算。

具有模块破坏值的弹药满足破坏资格才累计：动能要求P≥A，反甲化学能要求P≥0.5A；生命伤害仍按各自公式。公共量表阈值T=100，每满阈值T从未重伤模块随机升级一级，扣阈值保余量；单击可多次，四模块正常到全重伤共8次即8T。每完成一个模块损伤等级的修复，公共破坏量表清零；开始维修或中断不清零，单纯恢复生命不清零。全部模块重伤后停止累计并舍弃余量，修复出可受损模块后新击穿恢复累计。不增加外部破坏值；高爆反人员弹无模块破坏值，不累计量表。满生命不消除模块伤。机械装填重伤不再停止，仅时间×5；状态与维修变化保持当前完成比例。

四模块改为观瞄／人员状态／装填／机动，旧维修顺序中的引擎映射机动；观瞄合并与新增人员状态后的完整维修优先级待重新确认，不自行推定，获得资源的模块可并行。须停车停火，命中或有效近爆中断未完成计时，安全后重来；完成扣费，已修保留。

弹药及装甲有碰撞体积，步兵班组共用碰撞体并保留个人逻辑位置。APS可选，全向简化，资格按武器类型，次数冷却型号独立；其他参数待定。

| 指令 | 行为 | 路径 |

| 基本移动 | 避障外尽量直线，不主动停车接敌 | 蓝色虚线 |
| 快速移动 | 按预计到达时间选路，不增加基础速度 | 绿色虚线 |
| 攻击移动 | 遇有效目标停车交战，结束继续原路线，不追击 | 红色虚线 |

硬化与非硬化路面影响装甲速度，步兵同速。无武器不能攻击移动，步兵不能倒车。路径选中才显示；后续任务虚线和编号，当前与后续均虚线。无效目标禁用符号，火炮准星、移动箭头。

### 局外移动设置

可选按组内最慢有效速度保持队形，或按各自速度。仅本次移动组参与，随地形与移动方式动态计算；乘客按载具，不可移动单位提示并排除。目的地分配不同落点。攻击移动交战单位退出速度协调，其他继续；独立新命令退出组。

避障优先，可暂打破队形，通过后恢复；快速移动仍各自选快路，不强迫同一路线。冲刺暂不受最慢速度限制。

### 任务队列

Shift追加，不按Shift替换并清空后续。各单位独立执行，移动到达、装卸完成、指定目标摧毁视为完成。持续攻击地面无结束条件，会阻塞后续。无法执行且目标已失效跳过提示；暂缺弹或空间不足等待。即时烟雾冲刺不入队不覆盖任务。

E在交互状态先退出交互，无交互则取消任务清队列；不启用被关闭武器、不关闭仅还击。H不清队列。混选资格分别检查，不支持单位保留原任务；运输车与车内乘客同选只执行车的移动。

### 地面单位移动碰撞（立即应用）

地面单位之间具有移动碰撞，敌我一致，不能直接穿过彼此。移动单位正常避让，停车单位不被自动推走。被单位暂时堵住时尝试绕行，无路可走则等待，不取消任务。步兵班组使用整体移动占用范围，不增加每名士兵独立堵路规则。搭载单位不额外占据地面空间，卸载须有有效空位，否则保持搭载。出生点生成同样遵守有效空位规则。

本条属于用户要求立即应用的核心设计变化，不默认延期至下一大版本；开发线应评估当前实现影响，在接下来开发中纳入。其他设计内容不因此自动扩大本轮开发范围。

### 残骸与场景障碍物

单位残骸仅作视觉表现，不作为战场可交互实体，不阻挡移动、弹丸或视野，不能选取、攻击、回收或重新操作，不保留补给，不二次殉爆。显示一段时间后消失，时长待定。撤离人员生成不依赖残骸。

场景障碍物被摧毁后换为破损外观，仍按原有范围阻挡移动、弹丸及视野，不新增坍塌碎片、缺口或高度变化。摧毁后不再受伤，不能被彻底清除。单位残骸与场景障碍物分别适用上述规则。

## 12 视野目标与开火

单位独立视野，侦察更高，具体数值后定。地形遮挡，并按第23节隐蔽倍率确定发现距离，不增加随机探测概率；同队共享视野。补给点无视野，乘客不额外提供视野。敌离开后灰色最后位置不更新生命位置；照亮旧位置未发现即清标记，不可直接单位攻击，可强制攻击地面。命中反馈统一处理，不另设强制攻击专用反馈规则。

### 选敌与接近

手动目标优先。局外自动策略选最近或最高伤害效率，后者按经防护预计有效伤害比较，不按价值分；同效率选最近。各武器独立，只选可见、射程内及路径有效目标；已有目标保持到失效，不因更优敌人出现反复切换。

局外接近策略选最长武器可开火或全部适用武器可开火。只计启用、有弹且能攻击该目标的武器，PDW正常参与。接近是初次开火准备，不是追击；到位后目标出射程不跟随，所有攻击都不追击。恢复短射程武器不再次前进。目标失视停止指定攻击并执行后续队列。

### 火炮与路径

地面曲射火力（弹道导弹除外）不自动开火，只接受T；目标超射程可初次接近最大射程，移速0无法自行接近。单点实际弹道有障碍则拒绝；区域模式按第19节逐目标或落点检查。不自动找绕障射击点。直射须无遮挡，间接可越障但检查实际弹道。地面目标可不可见。火炮无射界限制、无架设撤收时间，转向属于瞄准过程并与瞄准同步，瞄准配置必须容纳所需转向，不额外串行增加转向时间。

普通共用炮塔主炮和同轴共享朝向，独立站自行转向。手动目标优先定炮塔方向，自动主武器优先；机炮炮塔转速120°/秒，车长炮塔360°/秒；开火须完成瞄准且炮口朝向就绪。

### 仅还击

H开启后受伤害或压制前全部武器禁止开火，不积累瞄准或自动接近。受击解锁当前范围目标，安全一段时间重锁，受击刷新计时；时长待定。手动任务不绕过限制，火炮仍需T。H重启清触发，关闭不启用停用武器。

## 13 武器瞄准弹药与烟雾

每把武器独立移动射击资格、瞄准、装填，可同时射击不同目标。开火须武器启用、状态允许、弹药足够、目标有效、仅还击许可；火炮另需命令。信息面板可统一启停同型号武器，任何新指令不改变开关。

### 瞄准与装填

除地面曲射火力外的武器持续同目标瞄准一次后按射速装填连续射击；换目标或失视清瞄准。地面曲射火力的任务级瞄准及等待规则以第19节为准。禁移动射击武器移动清零，支持者可移动瞄准。停用、冲刺清瞄准；恐慌、失能只改变完成速度及散布，保留进度。瞄准与装填并行，两者完成才开火。

待发仅为火力流程计数，用于判断何时需要重新装填，不是独立弹药库存。实际发射才扣除对应弹种库存；换弹恢复待发计数，不转移、不重复扣除、不增加库存。补给只增加弹药库存，不缩短装填。换目标失视停攻击不重置装填，停用仍可装填；失能不暂停，待发计数保留。机械装填重伤只改变速度，不重置进度。弹匣齐射容量独立配置。

部分缺弹其他继续，全缺弹不自行找补给。手动攻击保留等待，补弹重新瞄准但不接近；攻击移动缺弹继续路线；火炮等待。目标灭完成，失视结束指定目标任务。

### 烟雾

X步兵车辆在自身位置释放，无投掷选点，不覆盖任务。失能与恐慌可用。烟雾遮断双方观察不挡实体和弹丸，其他友军有视野可保持目标可见；射手烟雾遮挡停止自动直射，可强制打地面；间接地面任务不取消。不直接解异常。

每单位独立库存和CD，成功扣弹开始冷却，补弹不重置CD，重叠各自计时不增强遮蔽。多选可用者释放、无库存冷却者跳过，共键冲突整组不执行。按钮显示CD条与可用数量，全部冷却显示最早恢复者；具体范围时长消耗后定。

## 14 兵牌、详细信息面板与鼠标交互

### 兵牌主体

兵牌是最小可独立指挥单位在场上的唯一权威位置指示：步兵以班组为最小单位，装甲以单车为最小单位。兵牌与单位当前模型的位置绑定，当前模型可使用自动生成占位模型，后续替换正式模型不改变兵牌规则。兵牌采用固定屏幕尺寸，不随世界缩放变化；Demo阶段密集单位兵牌不做自动偏移或避让，允许发生重叠，后续保留优化可能。

兵牌主体统一为玩家颜色矩形边框＋灰色填充背景＋中央单位识别图案。玩家颜色边框只承担归属识别。具体识别图案、美术图标、槽位尺寸及间距后续替换或细化，不改变本节信息结构。兵牌本体不附生命条，不常驻显示单位名称、武器、弹药、速度等详细数值。

人员正常时使用灰色填充；恐慌时兵牌主体改为黄色－灰色渐变填充；失能时改为红色－灰色渐变填充。该人员状态表达同时适用于步兵与装甲。步兵另在兵牌下方显示阿拉伯数字的当前班组人数，班组人数属于独立指示器，不归入生存状态指示器。

### 兵牌派生状态指示器

状态指示器均从兵牌位置派生，不独立代表单位。现行类别保留为生存状态、工作状态、开火、行为状态和搭载状态。具体图标以后加入，当前只固定框架、位置和语义。

| 类别 | 位置与规则 |
| --- | --- |
| 生存状态 | 人员状态通过兵牌主体背景表达。装甲另在右侧自上而下预留观瞄、装填、机动三个状态槽；正常隐藏，轻度受损黄、重度受损红 |
| 工作状态 | 兵牌左侧自上而下固定为镭射、禁火、交战中三个独立槽位；三者互不排斥，可同时存在；未激活时不显示具体图标 |
| 开火指示器 | 仅装甲单位使用，位于兵牌下方；统一白色进度条，只提示距离下一次开火的剩余时间。瞄准与装填同时存在时，显示预计更晚完成、即实际限制下一次开火时间的那一项；两者均完成时隐藏。当前机炮按机炮炮塔处理，车载武器仍指炮塔／车体派生的车载武器槽位中的武器 |
| 行为状态 | 保留独立类别，沿用现有可见性和行为规则；当前已定义的仅还击状态仍只对己方显示，不在详细信息面板重复 |
| 搭载状态 | 位于兵牌上方；仅搭载步兵时显示搭载人数，存在混合货物时仅显示搭载图标，不用数字表示混合载荷 |

受损状态对双方的可见性继续沿用既有规则：敌方仅在点亮时获得实时状态，失视后不泄露新的变化。所有兵牌派生状态均不增加悬停文字。

### 主HUD与详细信息面板

当前主HUD信息架构固定为：左侧预留单位订购／出动区域，右侧为战场信息栏，左下保留小地图，小地图右侧延伸为底部详细信息面板；中央主体尽量留给战场视野，仅叠加兵牌、选择反馈、订单指示及必要战术反馈。现阶段只固定信息架构与交互，不绑定最终美术；图标、字体、材质、单位缩略图等美术资源后续补充，允许使用字符、几何图形和临时矢量占位。概念预览图不属于基线资产，也不嵌入本文件。

底部区域按从左到右固定为“小地图｜武器信息｜单位摘要｜命令区”。单选后显示对应详细信息；详细信息面板不是兵牌，不承担场上位置指示。单位摘要只显示单位身份与总体存量信息：名称、单位类别／配置、总生命；步兵另显示存活／满编人数。兵牌已承担人员状态、装甲观瞄／装填／机动受损、工作状态、开火与搭载等状态提示，因此详细信息面板不重复这些状态；不显示视野、隐蔽等细数值。

武器信息区横向单排并列显示武器类型，超宽时横向滚动，不自动换成第二排。同型号武器合并为“武器名×N”，不展示炮塔、Mount、Weapon Slot或车体／炮塔派生关系；车载武器与班组基本武器采用相同汇总方式。每种武器下方按弹药种类分列该武器类型的当前合计库存，只显示合计弹药，不提供单把武器库存展开。弹药耗尽时保留该弹种并置灰，不因归零而隐藏。不同瞄准／装填进度仍按既有规则显示就绪数与总数，并分别表达瞄准与装填。烟雾属于单位能力，不作为武器或弹药卡单独列入武器区。

命令区采用固定3×3槽位，单位不具备某项操作时该槽位留空，不允许其他按钮补位。按从上到下、从左到右固定为：

| 行 | 左 | 中 | 右 |
| --- | --- | --- | --- |
| 1 | 冲刺／快速移动 | 攻击移动 | 倒车 |
| 2 | 烟雾 | 强制开火／T火炮 | 仅还击 |
| 3 | 镭射 | 装卸 | 返回基地 |

第一格按单位资格显示冲刺或快速移动：当前步兵无快速移动、装甲无冲刺，两者共用槽位且不需要二级菜单。第二行中格对普通直射单位显示强制开火，对火炮显示T火炮入口；当前地面UI中T仅作为火炮入口，其二级菜单覆盖原命令区位置。返回基地固定在右下角并使用黄褐色作为视觉强调。普通移动与普通攻击不设命令区按钮，继续使用既有地图直接交互；需目标的命令仍由地图右键确认，即时能力点击执行。仅还击按钮亮开暗关、混合半亮；仅还击状态仍只在己方兵牌旁显示，详细信息面板不重复。

### 多选与快捷选择

多选单位条目排序侦查→步兵→装甲→支援→飞机，同类按配置且不因状态跳位，超宽横滚。多选武器区显示多单位，菜单取可用操作并集。

单击场上兵牌或Tab循环单单位，保留原集合，指令只对当前单位；Shift+Tab恢复集合。Tab按面板单位条目顺序，阵亡退出删去，当前死亡切下一。双击场上兵牌选屏幕内当前可控同型号同配置单位，不含订单。

### 消息与交互

所有文字提示除当前操作类型外进入右侧战场信息栏，无悬停文字；重复原因去重，同批合并，可定位单位、淡出并展开历史。失败尝试或重要状态变化提示，不在鼠标经过时弹。正常成功靠动画路径反馈。左侧屏幕空间保留给单位订购／出动UI，不再承担消息栏。

普通左键选、拖框选、空地清空，Shift左键增减，Shift框选加入。指令选点右键确认、左键或E退出且不穿透选择；Esc只开菜单。手持订单暗化兵牌左放右取消，E取消订单。界面点击不穿透。

## 16 合作权限与掉线撤退

队友单位仅能查看，不能操作；己方单位不能搭乘队友运输车。共享视野、共享补给及共享镭射标记保留。不存在任何控制权转移。

玩家掉线后，可移动单位自动执行返回出生点退款，途中正常受击并计维护费。车内单位随运输车撤退，到达后与载具分别退款，不先卸载。自身基础移速为0的装备，自动触发主动放弃：无需人工确认，仍读条3秒且可被击毁；撤离人员生成后自动返基地。恐慌及失能步兵仍有移动能力，直接撤退，不因此触发放弃。

掉线时取消所有未生成订单（含手持、读秒及等待部署），全额退款释放名额。临时堵路不视为无法移动，继续等待通路。在线玩家继续对局，不暂停、不因队友掉线直接判负。当前不提供断线重连，不设计恢复任务等流程。

正常对局经济账户独立，各玩家初始1000、基础收入300分/分钟，不能直接转账。掉线后该玩家后续基础收入均分给在线队友，开局总基础收入保持不变。设开局玩家数N、在线人数n>0，每名在线玩家基础收入为300N/n分/分钟，每5秒到账25N/n；双人剩一人为600/分钟、50/5秒。维护费仍各自计算，不把掉线单位维护转嫁给队友。掉线玩家原余额、订单退款及撤退退款不分给在线玩家；掉线玩家不再领取基础收入。无人在线时不分配收入。

地面补给点不属于单个玩家，掉线不移除，按队伍归属继续服务。移动补给车随单位撤退，途中仅在正常停车服务条件成立时提供补给，不为补满队友而停留；携带库存随车撤离，不主动卸下。

## 17 部署受阻

读秒结束在出生点范围寻找最近有效空位。无空位时等待部署，保留费用与预留名额，不收维护；有空位后直接生成，无需重新读秒。等待期间可拿起订单暗化兵牌调整位置，放下重新完整读秒，取消全额退款。按读秒完成先后部署，但某个订单尺寸受阻不阻塞其他可部署订单。敌人接近不关闭出生点，新单位没有无敌保护。

已生成单位无法到达订单暗化兵牌所指示的目的地时，前往最近可达位置并提示，不自动退款；卸载空间不足保持搭载。

## 18 弹丸、制导与友伤

### 弹丸模拟与制导属性：待后续讨论

删除“弹道方式／基础弹道类型”作为正式字段及“仅两类基础弹道”的固定框架。单位类型保留“制导方式”属性，当前留空；武器模板中的制导方式属性同样留空，不预设具体取值、默认无制导或实现规则。具体弹丸运动、重力、轨迹、速度、飞行时间与制导耦合方式，待用户另开会话讨论并确认后填写。

本节其余已确认的散布、来源归属、碰撞结算与友伤规则继续保留，不以暂停具体运动模拟讨论为由自行改写。

散布在发射时决定方向或落点，命中时不额外掷命中概率。枪械的基础散布半径为固定世界空间数值，不随射击距离放大或缩小；人员状态及已明确的移动散布修正仍按各自规则乘算。射击距离不直接修改枪械标伤、散布或另加伤害倍率；距离对动能枪械伤害的影响仅通过实际穿深进入第10节防护—伤害公式。直射武器按目标当前速度计算提前量；转向变速可能使弹丸落空。普通间接炮击瞄准发射时确定的位置，不预测远期移动。

### 独立存在与归属

弹丸由服务器生成，独立记录飞行状态、弹药类型和固定发射来源（发射单位身份、所属玩家）。来源单位死亡、退款或改命令不取消已发射弹丸，击杀仍显示原发射单位并归原玩家。此处是规则归属要求，不指定程序类结构。

实际碰撞决定命中，首先碰撞有效对象后结算并消失；爆炸在实际碰撞位置发生。弹丸与地形、建筑及敌我单位碰撞。班组共用碰撞体，命中后的单兵伤亡仍按第9节结算。

### 友伤与开火检查

弹丸可被友军挡住，直击与爆炸都具有友伤，爆炸同时造成压制。生成时排除发射单位自身避免炮口自碰，后续爆炸仍可伤及发射单位。

直射自动开火及普通指定攻击在发射前检查友军遮挡；被挡则暂缓，不绕路、不追击。发射后友军进入弹道仍可中弹。G强制攻击跳过友军遮挡检查；火炮手动炮击不因落点附近有友军而拒绝。地形障碍规则仍有效。

误伤击杀显示实际发射单位并标注友军误伤，受害玩家记录死亡价值；射击方无击杀价值，不额外扣出动分。补给殉爆连锁沿用最初引爆者归属。

## 19 火炮T菜单与炮击任务

所有地面曲射火力（包括迫击炮、身管火炮、火箭炮）共用以下T菜单与炮击任务规则，仅通过T命令开火；弹道导弹除外，其精确打击机制另行确定。二级菜单覆盖原命令区位置。T与未来导弹精确打击、飞机精确投弹沿用共键互斥规则。

| 弹种 | 默认 | 烟雾 | 制导 |
| --- | --- | --- | --- |
| 范围模式 | 单点 | 跟踪 | 徐进 |
| 射击数量 | 一发 | 三发 | 全弹 |

每行单选并高亮。未携带弹种不显示对应按钮，位置留空，不移动其他按钮；已携带但耗尽保留置灰。多选显示弹种合集，命令只由携带对应弹种的单位执行，其他跳过并汇总提示。默认指该配置常规炮弹，不自动切烟雾或制导。制导不禁用任何范围模式。

局外设置默认三行选项，以及下次任务沿用上次选项或恢复默认。打开菜单与调整选项不影响当前任务；右键确认地图目标才替换或Shift追加。E只退出菜单交互。每项任务保存确认时设置，之后改菜单不改变已有任务。

### 单点／跟踪／徐进

单点攻击固定位置。目标超射程初次移动至最大射程，移速0无法接近则拒绝；弹道阻挡拒绝，不另找阵地。

跟踪以右键拖出圆形区域、松开确认，区域半径上下限待定。每次发射前从区域内被点亮或有最后已知位置的敌人选目标，优先当前可见，其次最后已知，同级轮流分配。当前可见用最新位置，失视用最后已知，不获取隐藏真实位置。可见目标离开区域后不再攻击；旧位置重新照亮且确认无目标时清记录。区域无目标则等待，不自动跳下一队列任务。

跟踪以中心点作为首次接近依据，进入其最大射程后停下，仅选区域内且在自身射程内目标，不继续追击。多炮尽量分配不同目标，目标少时允许重复；每次检查实际弹道，受阻目标跳过。

徐进以右键从起点拖到终点确认，红色虚线显示方向。沿线推进，不要求目标可见，不因发现敌人偏离。一发射起点；三发射起点／中点／终点；全弹按本次数量均匀覆盖全线。多门炮各自走完整路线，不互等。首次接近须使全线均处于射程内，找不到可执行位置则拒绝并提示。受阻落点跳过，不耗弹不计已发射次数；到路线终点结束，取消未完成轮数，不自动重复。

烟雾沿用相同落点规则，不判断己方掩护需求。徐进不会自动生成或移动镭射标记；弹丸如何使用标记待后续制导讨论确认。

### 数量与打断

一发／三发按每门炮实际发射的弹丸数量计算，不按整轮齐射计算；四门三发共十二发，火箭炮三发即三枚火箭。连续发射间隔、待发容量及整组装填时间按武器配置设置，不增加操作菜单。跟踪数量是每门炮整个任务的预算，不是每个目标各打一轮。全弹取每门炮开始执行时所选弹种的实际弹药库存总量（不另加待发计数），途中补给不追加；需要重新装填时任务继续等待。三发不足则打完现有弹药结束并提示。各炮独立瞄准装填完成任务，不强制齐射。

普通移动、快速移动、倒车、新炮击命令替换当前炮击任务并取消剩余数量；Shift追加在任务完成后执行。已发炮弹继续存在；制导行为待后续讨论确认。移动清瞄准，装填沿用武器规则；停止后不恢复已替换任务。跟踪等待可通过E取消，E清队列规则不变。

### 瞄准与散布

每项地面曲射任务开始时仅进行一次完整瞄准。同一任务内跟踪更换目标、徐进推进落点不重新瞄准，不增加落点调整时间；后续发射只受装填及武器连续发射间隔限制，仍须朝向就绪才发射，转向与其他准备并行。无目标或弹道受阻等待时保留已完成瞄准。移动或替换任务清除瞄准进度；失能不清除瞄准，只应用状态惩罚；开始新任务或从中断恢复炮击时重新完整瞄准。无架设撤收时间及射界限制。

每次发射独立计算散布：单点围绕固定点，跟踪围绕本次选取的目标位置，徐进围绕本次路线落点。散布范围按武器与弹种设置，数值待定；暂不加入连续射击精度递增、校射或额外散布模式。

制导相关的具体发射、激活及引导行为待后续讨论确认，不沿用历史100米激活规则作为现行要求。

## 21 后续PVP专用规则

两阶段各10分钟，只用于结算；20分钟按双方累计总分判断，同分加5分钟。占领和击杀分别推进独立量表，同等重要，兑换系数待定。阶段将所有累计值直接折算含未满部分，清空进度，不重置战场状态。加时仍同分的处理及精度容差待定。

占领量表按比对手多占点数增长：v×max(己方点数−敌方点数,0)，不扣历史分。据点敌方／中立／己方三态，先清敌再填己，固定速度；有单位即可推进，状态和数量不影响速度，双方在点暂停，无人保进度。补给点不能占点。

消灭按配置价值，单兵伤亡、失能、模块伤不单独计分；补给毁损10分/t。主动放弃只给对方少量价值，自身为击杀者；正常被动逃生不降低原装备价值。占领和击杀不直接产生出动收入。

## 23 场景实体、驻扎与比例减伤

### 场景实体分类

场景实体由服务器统一管理，可由地图预先放置，不必属于中立作战单位；不参与单位卡、维护费或单位价值KD。房屋不取得玩家归属，只记录内部人员及其队伍。

| 类型 | 规则 |
| --- | --- |
| 树林 | 范围内隐蔽×2；无物理碰撞，不阻挡移动、弹丸，也不额外遮断视线 |
| 障碍物 | 物理遮挡弹道与视线；移动阻挡沿用场景设置 |
| 房屋 | 遮挡弹道与视线，可进驻步兵；毁后保留阻挡但不能再次进驻 |

树林范围统一以单位中心判定；步兵按班组中心，整班同时获得／失去加成，车辆按自身中心。不逐士兵判定，重叠树林只翻倍，不叠加。树林是否可受伤／摧毁未确定，不自动套用房屋规则。

### 房屋进驻

房屋仅设置最大容纳人数，不计算载重；班组按满编人数占容量，伤亡不减占用，只能整班进入。同队不同玩家可以共同驻扎，各自指挥自己的步兵。已有敌方驻军时不能进入，不增加室内近战争夺。

选步兵右键房屋进驻，U离开；直接移动命令先离开再前往目的地。进出统一短读条，时长待定，不受恐慌／失能延长。人员生命、人数、压制及武器手动开关不因进出改变。

每把武器单独设置“房屋内可开火”标签；不允许的停火，允许的正常使用，不因某把武器禁用而禁止整班进驻。离开后恢复室外资格，不打开玩家关闭的武器。弹丸从房屋几何中心发出，忽略所在房屋自身碰撞；其他地形、建筑和单位照常阻挡，不计算窗户或射界。

### 攻击驻军与房屋毁损

被发现驻军仍可作为独立单位目标，位置视为房屋中心。指定攻击驻军的弹道忽略所在房屋阻挡，按步兵防护及减伤结算。指定攻击房屋只直接扣房屋生命，同一次直击不同时扣二者；爆炸可以分别伤及房屋与内部班组，每个对象结算一次。

房屋被毁强制内部步兵离开，承受固定逃生伤害与压制，不重复承受摧毁房屋的同一次攻击伤害；固定逃生数值待定，沿用运输损失思路。毁后房屋换破损外观，保留原阻挡范围，不再受伤、不能清除或再次进驻。

### 减伤比例与减伤无视

比例减伤在动能／化学防护结算之后应用，浮点伤害：

有效减伤＝最高适用减伤比例×（1－弹药减伤无视比例）。

最终伤害＝防护结算后伤害×（1－有效减伤）。

比例减伤仅由掩体保护提供。步兵本体无自身比例减伤，平静、恐慌、失能状态均不赋予比例减伤；无掩体步兵按防护公式直接结算生命伤害。不同类型掩体分别配置减伤比例，具体数值后续确定，不沿用房屋统一50%的旧默认值。步兵动能／化学能防护仍保留，不与比例减伤混同。

多个适用掩体减伤来源只取最高，不叠加。人员状态变化不取消已有掩体保护。掩体自身不自动享受其向驻军提供的减伤；固定逃生伤害不享受该房屋驻扎减伤。

减伤及无视只改变生命伤害，不改变击穿判定、动能／化学防护、压制或模块破坏，不绕过遮挡。每把武器设置减伤无视比例，范围0%～100%，具体数值以后定义，不预设直射0%或曲射100%。普通无其他来源的比例减伤默认为0%，减伤比例范围0%～100%。

### 通用隐蔽、暴露与消音

单位具有基础隐蔽倍率，普通基准1；发现距离＝观察者视野距离÷目标有效隐蔽倍率，同时检查地形视线，并沿用队伍共享发现。基础数值按单位以后设置。

实际发射武器后，有效隐蔽倍率暂降至1；停火一段时间恢复基础与树林加成。移动、瞄准、装填不触发额外暴露，离开树林立即取消树林加成。开火不全图点亮，仍需满足发现距离与视线。

每把武器可有“消音”标签，缩减比例为统一固定值，不随武器、阵营、人员状态等变化，具体值待定：该武器暴露持续时间＝基础暴露时间×（1－消音缩减比例）。每次发射刷新该武器造成的暴露，直到班组所有武器造成的暴露均结束才恢复隐蔽。消音不改变瞬间隐蔽损失，不减伤，不新增声音传播或听觉侦测；持续时间与缩减比例待定。

烟雾保持遮断视线，无物理碰撞，不挡移动弹丸，不提供隐蔽倍率。开火不能看穿烟雾；烟雾内仍计算通用暴露，但发现必须满足视线条件。烟雾继续阻断镭射。

## 24 统一单位与武器设计流程

所有部队共用基础字段和适用标签，不按步兵／车辆／火炮另建互不兼容的模板。依次设计单位本体→武器→给单位分配武器形成配置→最后生成单位卡。

### 单位属性、设计分类与能力标签

单位类型与生命、防护、班组人数等同属单位属性，不是标签。轮式／履带式及炮塔类型仅为设计分类，不要求增加对应游戏标签或专用分类字段；其结果以移速、越野惩罚、转速、槽位及朝向配置表达。

单位能力标签共六项：冲刺、烟雾×1、烟雾×4、镭射、移动补给、APS。APS仅注册标签，功能暂缓开发。烟雾×1与烟雾×4互斥，分别提供对应使用次数。只有检测到冲刺、任一烟雾或镭射标签，才启用菜单中对应能力；拥有标签后仍检查冷却、余量、状态、攻击／照射资格等既有使用条件，不取消原有禁用规则。快捷键与菜单采用相同资格判断。烟雾补充规则仍沿用既有补给规则。

移动补给属于能力标签，不另设补给标签类别。补给资格、容量等仍为属性；有补给能力且无移动补给标签时采用建造补给点规则，无补给能力的普通单位不获得建点能力。“被镭射标记”是服务器运行状态，不是配置时的固有能力标签。

## 24A 通用武器规则与已确认独立武器性能

### 目标类型与攻击资格

目标类型独立于组卡类别、生命伤亡及运输规则，分为步兵、地面载具、直升机、固定翼飞机、掩体工事。步兵包括普通班组、架设武器班组及撤离人员；掩体工事包括房屋、障碍物、补给点等可攻击对象。树林与烟雾不因此成为攻击目标。“场景实体”仍作为地图对象统称。

每把武器配置允许攻击的目标类型列表，先检查选敌与单位目标开火资格，再选弹。该列表不提供碰撞或伤害免疫；合法发射的弹丸误中其他类型仍正常结算。G指定单位仍检查攻击资格；G对地面位置可强制开火，不增加“允许地面强制开火”属性。反甲武器的反人能力由数值限制。

### 多弹种与装填通则

所有武器统一把装填视为开火准备，已装填状态不锁定弹种。发射瞬间从有库存、满足攻击资格的弹种中按对当前目标的预期有效单发伤害选择并扣库存；考虑命中面防护、当前距离穿深、适用比例减伤与减伤无视。剩余数量不影响排序，库存不足一次结算消耗量时排除；高爆反人员弹允许攻击装甲。相同伤害沿用上次弹种，首次按配置顺序。不增加独立选弹任务、切换动作或等待，不因换弹种清零装填或重新装填。

多弹种共用每把武器的装填进度与待发容量，库存分别显示。弹匣类仍保留容量、不满弹匣及换弹规则。主、副武器可同时开火，不在不同武器之间择一停火。自动选敌的最近／最高伤害效率策略保持独立。

武器本体定义性能、槽位、最低操作人数及资格；携带数量归单位分配配置，不固定在武器定义上。数量5不自动等于5枚齐射，齐射须配置相应武器实例与操作岗位。

### 步兵武器

#### 设计分类

步兵武器按设计用途分为普通武器与班组武器。当前普通武器仅包括基础步枪、个人防卫武器（PDW）和一次性火箭弹；除非后续规则明确声明为普通武器，其他现有或新增步兵武器默认视为班组武器。轻机枪、无后坐力炮、射手步枪与霰弹枪均属于班组武器。

武器设计分类与武器槽位、最低操作人数分别生效。一次性火箭弹属于普通武器，但仍占1个副武器槽；无后坐力炮属于班组武器，占1个主武器槽＋1个副武器槽。特殊装备是独立概念，不因武器属于班组武器而自动产生特殊装备占用。

默认弹匣容量30发，已声明的武器使用自身容量，特殊声明优先。机炮默认穿甲1个弹匣、高爆4个弹匣；步兵武器默认五个弹匣备弹。均指实际总可用库存，不另加一个待发弹匣。

| 武器 | 容量 | 默认库存 |
| --- | ---: | --- |
| 小口径机炮 | 30发 | 穿甲30＋高爆120发 |
| 大口径机炮 | 10发 | 穿甲10＋高爆40发 |
| PDW／普通步枪 | 30发 | 150发 |
| 轻机枪 | 150发 | 750发 |
| 霰弹枪 | 10发 | 50发 |

待发计数与多弹种库存分别记录，发射时选择弹种并扣库存；换弹只恢复火力流程计数，不预先锁定或分配弹种。已有明确弹药数量的特殊武器沿用声明，不将一次性发射器库存擅自换算为五个弹匣。

### 后续设计入口与待定

各阵营爆炸半径、散布、穿深距离衰减参数和压制恢复正式参数仍待定。霰弹枪仅确认容量、射速及库存，伤害不套用机炮数值。独立武器的已确认性能继续生效，不自动形成任何正式单位配置。

### 底盘机动、转向与车载武器（本批确认）

界面默认显示公路速度，步兵速度也以此为基准。越野只降低位移速度：步兵0%惩罚、履带20%、轮式50%；沿用状态／模块减速乘算，不自动降低转向速度。界面以千米/时显示。

普通步兵与架设火炮（包括迫击炮）转向360°/秒，覆盖此前火炮180°/秒及转向仅动画规则。车体自动将正面朝向正在攻击的敌人，覆盖不自动转向旧规则；与移动命令冲突时移动命令优先。非倒车移动先旋转车体再位移；倒车保持朝向，当前讨论阵营倒车减速90%（速度剩10%），是阵营特色，不推广为全阵营默认。

转向与瞄准同步，配置瞄准时间须容纳转向，不把两者串行相加。机炮每次完整瞄准开始随机取2～3秒，不在过程中重抽；炮塔取最短方向转动，转速120°/秒，180°需1.5秒。完成瞄准且炮口朝向就绪才能开火，不要求车体也朝向目标；车体转向耗时由具体配置转速计算。

武器移动射击资格及移动散布惩罚按配置表达，散布惩罚与人员状态散布乘算；不额外延长瞄准、不改变命中后伤害。开始／停止移动不重置瞄准、射击间隔和换弹，停车后后续发射恢复正常散布。

机炮注册为机炮炮塔：主武器为机炮，每炮塔默认1个同轴车载武器槽，共享朝向，独立火力流程与库存，可同时开火。手动目标优先定炮塔方向，自动时主武器优先。每车默认1个车长位置，表示无主武器、自动生成1个同轴车载武器槽的独立炮塔，转速360°/秒；装入武器不再生成新炮塔。履带底盘默认1个车体武器槽，轮式默认无，随车体朝向。特殊声明优先。

每个车载槽自动引用本阵营车载武器，初始套用轻机枪数据，可按阵营特色修改。每门特殊弹匣450发，五弹匣总库存2250发；三发合一、1.5秒／抽象弹丸，未声明机械时人工换弹3秒。不额外加待发库存。轻机枪未给出的参数不自动补填。

### 阶段范围与通用移动补给约束

侦察、支援的进一步设计及开发延期至Demo完善后，与空军一起推进；已确认规则保留。APS注册为单位能力标签但暂不继续开发。正式Demo须实现单位编辑器，具体规格见第22节。

移动补给载具不能通过正常补给消耗以外的主动方式移除补给：不能丢弃、卸下建点或转给其他对象；被毁库存损失沿用摧毁规则。登车时现有补给计入总载重，容量不足则拒绝并在右侧战场信息栏提示“载重不足”。乘客固定占位与重量不随伤亡或弹药消耗降低；实际补给消耗释放载重空间。具体移动补给单位的服务范围、速率、携带上限及本体参数须在框架内另行配置。

### 临时测试值（非正式平衡定稿）

用户允许未定数值采用临时测试值。仅用来运行及测试，必须在配置与交接中标明临时；后续正式设计可替换，不将测试结果当成已完成平衡。临时值须服从第0节授权边界，已有正式数值优先，PDW、普通步枪及轻机枪杀伤与穿深锚点已正式确认；其余缺失参数须明确标为临时，不伪造为已存在的正式数据。
