# Prototype 0.5G：间接弹道按距离选速

## 来源与范围

用户明确要求按距离选速；以后DATA不记录非直射弹药固定初速；预期M252全有效射程实际落弹在20秒内。本轮作为0.5G，不进行0.6，过程为以后火炮提供参考。基线DB-2026-10-06-40，第18节为规则入口。本记录描述实际实现与限制，不增加独立规则授权，也不创建复检步骤文档。

## 审计与最小修改

原发射使用225m/s高根，100～1800米约44～45秒，顶点约2500米。固定初速不仅被求解器使用，也被T提交、实际发射、弹丸入池及红线预览检查。只改一处会导致拒射或预览／服务器不一致。

现在把非直射选速放在GravityBallistics.indirect，T资格、实际发射和名义预览共用。实际发射仍经FiringFrame取得真实枪口与目标状态，散布一次，再解算。弹丸池只消费权威初始速度，普通30Hz推进、点碰撞、边界终止及累计距离不变。

AmmoDefinition新增非导出的distance_selected_launch内部标记，适配器从既有Weapon Class推导（当前仅迫击炮）。它不是新增DATA弹道类型字段，不添加单位能力，不进入网络。未知直射初速仍缺失并拒射。未来新增火炮须明确其已有分类与能力，不能因化学能或爆炸半径推定为间接弹药。

## 算法与参数

散布后位移d，L=|d|，高度差H=d.y，全局g10：

- v(t)=d/t−0.5*g_vector*t。
- |v|²=L²/t²+g*H+g²*t²/4。
- 最小速度时间t_min=sqrt(2L/g)。
- 实现取t=1.04*t_min，再由v(t)算实际初速度。

1.04使t位于较长时间高支路，同高角度约47.25°；不是逼近垂直的旧弧线。该系数是集中可调整的最小实现选择，允许依据后续观感调整；不是正式弹药初速、角度下限或装药档位。20秒为用户明确的当前上限。无正解、非有限值或t>20时拒射，不减速播放、不切低抛、不强制寿命。放宽或更改策略须重新验证。

M252最大1800米低于本策略可行距离约1849米，留下散布／枪口位置余量。未来更大射程不能照搬全程20秒要求：保持g10高支路存在物理下限。时间从实际发射到实际地面碰撞，不包含转向和瞄准。

## 低速曳光可读性与选速成本

来源：用户确认0.5G通过，要求迫击炮弹更亮、曳光更长，并计算分级初速开销、判断是否需要简化。实际并无档位搜索：连续解析仅在服务器T请求校验和实际发射时调用；飞行中不重新选速，本地预览不占服务器解算。

仅客户端ProjectileVisuals调整：公开运动速度大于0且≤200m/s时，亮段时间由0.012增至0.08秒、淡尾由0.012增至0.06秒，亮段下限2米，两段上限各保持15米；线条半宽0.035增至0.07米，颜色由(1,0.9,0.2)变为(1,1,0.6)。Alpha仍从头至尾衰减，终止保留0.12秒，历史裁剪仍是实际可见长度上限。900m/s高速曳光仍为10.8+10.8米、原色和原宽。此规则是基于公开速度的临时可读性参数，可能作用于其他未来低速弹丸，不添加身份或弹种网络字段。未引入Glow/Bloom或渲染框架重构；通过更浅颜色与更宽像素覆盖提高辨识度，实际亮度仍需设备观感确认。
