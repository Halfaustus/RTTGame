# Prototype 0.5E：权威开火事件与装填（2026-10-04）

采用实际工作区 **DB-2026-10-04-17**，继承已授权同步的0.5A/B/C空间规则及0.5D配装。基线未修改。0.5D原有108项自动验证不作为本轮测试数量。

## 实际实现与边界

`AimingSimulation`继续负责目标、资格、瞄准与朝向；新增`FireSimulation`复用同一资格接口，在发射前再次检查。`RuntimeWeaponInstance`拥有独立`WeaponFireState`，分别保存射击间隔、装填完成比例、失败原因、上次弹种及事件序号。共享炮塔不共享这些状态或库存。

发射瞬间经纯计算`AmmoSelection`选择弹药，再在无yield的服务器操作内一次扣除库存与待发计数并生成事件。同伤沿用上次弹种，首次按定义顺序；库存数量不参与排序。计算采用正式动能／化学防护公式、权威距离与防护方向，以及输入中适用减伤的最大值与减伤无视比例。没有对目标施加任何结果。

- 枪械、车载机枪及B/C机炮：每次3发，间隔1.5秒。A机炮每次1发、间隔1秒、容量10、机械换弹4秒；B/C容量30、人工换弹3秒。既有标伤未乘3。
- 普通连射武器人工换弹3秒。射击间隔与装填并行：步枪首弹匣最后一次在13.5秒，下一弹匣首次在16.5秒；没有额外串行1.5秒。
- 无后坐力炮每次1发，发射后准备6秒；隔离火箭弹岗位夹具准备3秒。两种8人摩托化班及A/B/C配装不变，防守班5具火箭弹仍为未分配班组库存，无运行发射器。
- 停用仍推进装填；人工人员状态与装填模块时间倍率乘算、保留完成比例。机械装填不使用人员倍率。瞄准与装填并行，换目标不重置装填，补充库存不缩短装填。
- 换弹只恢复待发计数到`min(容量,实际剩余库存总量)`，不扣、转移或增加库存。该不满弹匣口径沿用0.5D初始化。不足一次消耗不能发射。
- 生产网络tick在瞄准后推进火力流程；历史伤害夹具开关仍隔离，不会由新发射事件启动旧战斗链。

**已完成正常有弹配置的开火调度→选弹→扣弹→装填闭环。没有弹丸实体、飞行、碰撞、命中、生命伤害、防护结算、压制、模块破坏或爆炸。** 纯选弹预期伤害数值不是已应用的伤害。未重构HUD、兵牌、目标搜索、补给或火炮系统。

## 接口与时间策略

事件字段：`event_id`、`tick`、`time_seconds`、`emission_sequence`、`weapon_instance_id`、`unit_id`、`slot_id`、`target_kind`、`target_id`、`target_position`、`ammo_definition_id`、`consumed`、`position`、`yaw`。不包含已结算伤害。实例与序号提供稳定身份，同一tick重复调用不推进时间或再次扣弹。

计时用实际dt。单次advance每门武器最多发射一次；大dt只推进当前计时，不用一次当前资格检查补造多个历史事件，不保留超额时间用于立即补发。生产仍按既有60Hz固定simulation tick推进，每tick重新检查。此策略是避免积压补发的实现边界，不是新的武器射速规则。

权威内部状态仍10Hz同步，增加库存、待发计数与火力状态；发射事件使用独立可靠RPC批次和`weapon_fire_received`信号。客户端`PresentationFeed`按实例序号去重，缓存随reset／death清理，消费者无扣弹权限。未执行ENet客户端测试，不宣称实网验收。

正式容量、库存、间隔、装填时长和倍率未调整。沿用0.5D临时枪械瞄准／移动资格、攻击列表、A射程、角度与距离容差，10Hz未改。枪械锚点与共享弹药保留；LMG400～600m穿深保持5。

缺项明确失败，不静默降级：
- 耗尽库存且装填完成后，再补充库存如何恢复不足的待发计数尚无正式规则；报告`pending_recovery_undefined`，不自行增加自动重装／即刻就绪机制。本阶段不实现补给。
- 强制地面目标缺少选弹评分所需的目标防护语义，报告`ground_selection_configuration_missing`；不伪装单位或固定伤害排序。
- 当前掩体／人员／模块状态通过既有可注入权威输入读取；未新增房屋、人员状态生成或模块损伤系统。没有配置时不能假称完整环境战斗已经实现。
- 枪械正式曲线系数、既有未定义正式瞄准／移动资格、火箭弹个人岗位和霰弹枪性能仍待确认。
